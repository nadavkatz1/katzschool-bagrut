לפני שמתחילים

זה השאלון הראשון של 5 יחידות לימוד בתוכנית החדשה. יש בו שמונה שאלות בארבעה פרקים: שאלות קצרות (שאלה 1), אינדוקצייה, סדרות והסתברות (שאלות 2 ו-3), גאומטרייה וטריגונומטרייה במישור (שאלות 4 ו-5), וחשבון דיפרנציאלי ואינטגרלי (שאלות 6 עד 8).

עונים על חמש שאלות: על שאלה אחת לפחות מן הפרק הראשון או השני, ועל שאלה אחת לפחות מכל אחד מן הפרקים השלישי והרביעי. כל שאלה שווה 20 נקודות, וחמש שאלות הן 100 נקודות. מי שעונה על יותר מחמש שאלות, נבדקות לו רק חמש התשובות הראשונות שבמחברת. בשאלה 1 עונים על שניים מארבעת הסעיפים א עד ד, וגם שם נבדקות רק שתי התשובות הראשונות. השאלון אינו מפרט ניקוד לתת-סעיפים.

משך הבחינה ארבע שעות ורבע. מותרים מחשבון לא גרפי ודפי הנוסחאות המצורפים.

כאן פתורות כל שמונה השאלות, ובשאלה 1 כל ארבעת הסעיפים, כדי שכל בחירה אפשרית של תלמיד תהיה מכוסה. בכל שאלה מופיעים הנתונים, השלבים והנימוק לכל שלב, ובסופה הערה קצרה על המקום שבו נופלים.

פרק ראשון: שאלות קצרות

שאלה 1, ארבעה סעיפים קצרים (20 נקודות)

עונים על שניים מן הסעיפים. כל סעיף כאן עומד בפני עצמו.

סעיף א: סכום ריבועי המספרים הזוגיים

(1) צריך להוכיח שלכל n טבעי

2² + 4² + 6² + ... + (2n)² = 2n(2n + 1)(n + 1) / 3

באגף שמאל יש n מחוברים: הריבועים של 2, 4, 6 וכן הלאה עד 2n. כדאי לשים לב לזה כבר עכשיו, כי בצעד האינדוקצייה נצטרך לדעת מה המחובר הבא.

בדיקה עבור n = 1. באגף שמאל מחובר אחד, 2² = 4. באגף ימין

2 · 1 · (2 + 1) · (1 + 1) / 3 = 2 · 3 · 2 / 3 = 4

הטענה נכונה.

הנחת האינדוקצייה. נניח שעבור n טבעי מסוים מתקיים

2² + 4² + ... + (2n)² = 2n(2n + 1)(n + 1) / 3

צעד האינדוקצייה. נוכיח עבור n + 1. המחובר הבא בסכום הוא הריבוע של המספר הזוגי הבא, 2(n + 1) = 2n + 2. לכן, לפי ההנחה,

אגף שמאל = 2n(2n + 1)(n + 1) / 3 + (2n + 2)²
= 2n(2n + 1)(n + 1) / 3 + 4(n + 1)²

נוציא את n + 13 מחוץ לסוגריים. את המחובר השני נכתוב כ-12(n + 1)² / 3:

אגף שמאל = n + 13 · [2n(2n + 1) + 12(n + 1)]
= n + 13 · [4n² + 2n + 12n + 12]= n + 13 · (4n² + 14n + 12)= 2(n + 1)(2n² + 7n + 6) / 3= 2(n + 1)(n + 2)(2n + 3) / 3

(בדיקת הפירוק: (n + 2)(2n + 3) = 2n² + 3n + 4n + 6 = 2n² + 7n + 6.)

אגף ימין של הטענה עבור n + 1 הוא

2(n + 1) · (2(n + 1) + 1) · ((n + 1) + 1) / 3 = 2(n + 1)(2n + 3)(n + 2) / 3

שני האגפים שווים.

מסקנה. הטענה נכונה עבור n = 1, ומנכונותה עבור n נובעת נכונותה עבור n + 1. לכן היא נכונה לכל n טבעי.

(2) הסכום 4² + 6² + ... + 100² הוא כמעט הסכום מסעיף (1). המחובר האחרון הוא 100² = (2n)², ולכן n = 50. נחשב את הסכום המלא, מ-2² ועד 100²:

2 · 50 · (100 + 1) · (50 + 1) / 3 = 100 · 101 · 51 / 3 = 100 · 101 · 17 = 171,700

בסכום שלנו חסר המחובר הראשון, 2² = 4. לכן

4² + 6² + ... + 100² = 171,700 − 4 = 171,696

הערך של הסכום הוא 171,696.

איפה נופלים בסעיף א. בצעד האינדוקצייה מוסיפים (n + 1)² במקום (2n + 2)², כי שוכחים שהמחובר הבא הוא ריבוע של מספר זוגי. בסעיף (2) מציבים n = 100, כי רואים 100² ומתבלבלים בין 2n ל-n, או שוכחים להחסיר את 2² שאינו בסכום.

סעיף ב: טרפז שאלכסוניו מאונכים

הנתונים. ABCD טרפז, AB ∥ CD. הנקודה O היא מפגש האלכסונים AC ו-BD. נתון ∢BAO = ∢CDO.

(1) נשתמש פעמיים בזוויות מתחלפות בין ישרים מקבילים.

  • הישר AC חותך את המקבילים AB ו-CD, ולכן ∢BAC = ∢ACD, כלומר ∢BAO = ∢OCD.
  • מן הנתון ∢BAO = ∢CDO, ולכן ∢OCD = ∢ODC.
  • במשולש OCD יש שתי זוויות שוות, ולכן הוא שווה שוקיים: OC = OD.

ובאותה דרך עם האלכסון השני:

  • הישר BD חותך את המקבילים, ולכן ∢ABD = ∢BDC, כלומר ∢ABO = ∢CDO.
  • מן הנתון ∢CDO = ∢BAO, ולכן ∢ABO = ∢BAO.
  • במשולש OAB יש שתי זוויות שוות, ולכן OA = OB.

עכשיו נשווה את המשולשים AOD ו-BOC:

OA = OB (הוכח)
OD = OC (הוכח)
∢AOD = ∢BOC (זוויות קודקודיות)

המשולשים חופפים לפי צ.ז.צ, ולכן AD = BC. לטרפז שתי שוקיים שוות, ולכן הטרפז ABCD שווה שוקיים.

(2) עכשיו נתון שהאלכסונים מאונכים, BO = 3 ו-DO = 4. מסעיף (1) גם AO = BO = 3 ו-CO = DO = 4.

במשולש DOC הזווית O ישרה, ולפי משפט פיתגורס

DC = √4² + 4² = √32 = 4√2

הקטע OF מקביל לבסיס DC. נסתכל על המשולש BDC: הנקודה O על הצלע BD, הנקודה F על הצלע BC, ו-OF ∥ DC. לכן △BOF ∼ △BDC, ויחס הדמיון הוא

BO / BD = 3 / (3 + 4) = 37

ומכאן

OF = 37 · DC = 37 · 4√2 = 12√27 ≈ 2.42

OF = 12√27, בקירוב 2.42.

בדיקה מן הצד השני: במשולש ABC הקטע OF מקביל ל-AB, ו-AB = √3² + 3² = 3√2. היחס הוא COCA = 47, ולכן OF = 47 · 3√2 = 12√27. אותה תוצאה.

איפה נופלים בסעיף ב. לוקחים את היחס BOOD = 34 במקום BOBD = 37. יחס הדמיון הוא בין צלע המשולש הקטן לצלע המשולש הגדול כולה, ו-BD כולל את שני הקטעים. בסעיף (1) מסתפקים ב-OA = OB ולא מגיעים לשוקיים עצמן.

סעיף ג: f, f′ ו-f″ לפי הגרפים

(1) נקרא כל גרף לפי שני דברים: איפה הוא עולה ואיפה יורד, ואיפה יש לו נקודות שבהן המשיק אופקי. הנגזרת של פונקצייה מתאפסת בנקודות האלה, חיובית איפה שהפונקצייה עולה ושלילית איפה שהיא יורדת.

גרף II. הוא עולה משמאל, עובר את ציר ה-x בנקודה שבה המשיק אופקי, ממשיך לעלות עד נקודת מקסימום אחת (מימין לציר ה-y), ומשם יורד לאט ונשאר מעל ציר ה-x.

גרף III. הוא אינו שלילי משמאל: יורד, נוגע בציר ה-x ועולה חזרה, וחיובי עד שהוא חותך את ציר ה-x בנקודה אחת מימין לציר ה-y. משם והלאה הוא שלילי.

זה בדיוק מה שהנגזרת של גרף II צריכה להיות:

  • בנקודה שבה למשיק של גרף II יש שיפוע אפס (על ציר ה-x משמאל), גרף III נוגע באפס, ואינו מחליף סימן. גרף II אכן ממשיך לעלות משני צדי הנקודה הזאת.
  • בנקודת המקסימום של גרף II, גרף III חותך את ציר ה-x מחיובי לשלילי.
  • בכל מקום שבו גרף II עולה, גרף III חיובי, ובכל מקום שבו גרף II יורד, גרף III שלילי.

לכן גרף III הוא הנגזרת של גרף II.

גרף I. הוא שלילי משמאל, חותך את ציר ה-x, חיובי, חותך שוב, שלילי, חותך בפעם השלישית, ומשם חיובי. שלוש נקודות חיתוך עם ציר ה-x. גם את זה נבדוק מול גרף III: גרף III יורד עד נקודת המגע שלו בציר ה-x, עולה עד מקסימום מקומי (משמאל לציר ה-y), יורד עד מינימום (מימין), ושוב עולה. יורד, עולה, יורד, עולה: שלילי, חיובי, שלילי, חיובי, וזה בדיוק סדר הסימנים של גרף I. לכן גרף I הוא הנגזרת של גרף III.

ההתאמה: f(x) הוא גרף II, f′(x) הוא גרף III, ו-f″(x) הוא גרף I.

שני סימנים נוספים מאשרים את זה, מן הנקודות שעל ציר ה-y:

f′(0) = 2 > 0 וגרף II אכן עולה כש-x = 0
f″(0) = −2 < 0 וגרף III אכן יורד כש-x = 0

אף סדר אחר לא עובד. למשל, אילו גרף III היה f, הנגזרת שלו הייתה צריכה להתאפס בשלוש נקודות הקיצון שלו. לגרף II יש נקודה אחת בלבד על ציר ה-x, ולכן הנגזרת הייתה חייבת להיות גרף I. אבל אז גרף II, הנגזרת השנייה, היה צריך להתאפס בשלוש נקודות הקיצון של גרף I, וגם זה לא קורה.

(2) בנקודת פיתול הנגזרת השנייה מחליפה סימן. הנגזרת השנייה היא גרף I, והוא חותך את ציר ה-x שלוש פעמים, ובכל פעם עובר מצד לצד.

לפונקצייה f(x) יש 3 נקודות פיתול.

אותה תשובה מתקבלת מגרף III: נקודת פיתול של f היא נקודת קיצון של f′, ולגרף III יש שלוש נקודות קיצון (המינימום שנוגע בציר, המקסימום והמינימום).

(3) נקודת המקסימום של f היא (a , 5), כלומר f(a) = 5, ו-f′(a) = 0. מן הגרפים f(0) = 4, f′(0) = 2.

נבין מי מעל מי בתחום 0 ≤ x ≤ a:

  • f′(x) ≥ 0 שם, כי f עולה מ-0 עד a (גרף III יורד מ-2 עד 0).
  • f″(x) ≤ 0 שם, כי גרף III יורד לאורך כל הקטע הזה, מן המקסימום המקומי שלו (משמאל לציר ה-y) ועד המינימום שלו (מימין ל-a).

לכן גרף f′ מעל גרף f″ בכל הקטע, והשטח הוא

S = ∫ (f′(x) − f″(x)) dx מ-0 עד a

הפונקצייה הקדומה של f′ היא f, והקדומה של f″ היא f′. לכן

S = [f(x) − f′(x)] מ-0 עד a
= (f(a) − f′(a)) − (f(0) − f′(0))= (5 − 0) − (4 − 2)= 3

השטח הוא 3 יחידות שטח.

איפה נופלים בסעיף ג. בסעיף (2) סופרים את נקודות הקיצון של f במקום את החלפות הסימן של f″. בסעיף (3) מנסים למצוא נוסחה ל-f, ואין צורך בה: מספיקים ערכי f ו-f′ בקצוות. ועוד: שוכחים ש-f′(a) = 0 בנקודת המקסימום.

סעיף ד: פונקצייה רציונלית, סימן, גרף ושטח

הנתונים. f(x) = 2(x + 1) / (x² + 2x)², בתחום x ≠ −2, x ≠ 0.

(1) המכנה הוא ריבוע, ובתחום ההגדרה הוא אינו מתאפס, ולכן הוא חיובי לכל x בתחום. מכאן שסימן הפונקצייה הוא סימן המונה 2(x + 1):

f(x) > 0 ⟺ x + 1 > 0 ⟺ x > −1

מן הקטע הזה צריך להוציא את x = 0, שאינו בתחום.

תחומי החיוביות: −1 < x < 0 ו-x > 0.

(2) נאסוף את התכונות שאפשר לראות בגרף:

  • בתחום x < −2 ובתחום −2 < x < −1 הפונקצייה שלילית, ובתחום −1 < x < 0 ובתחום x > 0 היא חיובית. הגרף חותך את ציר ה-x בנקודה (−1 , 0).
  • ליד x = −2 המונה שואף ל-2 · (−1) = −2 והמכנה שואף לאפס מצד החיוביים. לכן f(x) שואפת למינוס אינסוף משני צדי האסימפטוטה x = −2.
  • ליד x = 0 המונה שואף ל-2, ולכן f(x) שואפת לפלוס אינסוף משני צדי ציר ה-y.
  • כש-x שואף לאינסוף או למינוס אינסוף, החזקה במכנה גבוהה מזו שבמונה, ו-f(x) שואפת ל-0.

עכשיו נפסול:

  • בגרפים I ו-II הענף השמאלי (x < −2) מעל ציר ה-x. שם f שלילית. נפסלים.
  • בגרף IV הענף האמצעי יורד מפלוס אינסוף ליד x = −2 עד מינוס אינסוף ליד x = 0. אצלנו הוא עולה ממינוס אינסוף לפלוס אינסוף. נפסל.

גרף III מתאר את f(x): הענף השמאלי מתחת לציר ה-x ויורד למינוס אינסוף ליד x = −2, הענף האמצעי עולה ממינוס אינסוף, חותך את ציר ה-x ב-(−1 , 0) ועולה לפלוס אינסוף ליד ציר ה-y, והענף הימני חיובי ויורד לעבר ציר ה-x.

(3) בקטע 1 ≤ x ≤ 4 הפונקצייה חיובית (סעיף 1), ולכן השטח הוא האינטגרל שלה.

נשים לב למבנה של f: הנגזרת של x² + 2x היא 2x + 2 = 2(x + 1), וזה בדיוק המונה. כלומר f היא מהצורה u′u², כאשר u = x² + 2x. הפונקצייה הקדומה של u′u² היא −1u, ולכן

∫ f(x) dx = −1 / (x² + 2x) + C

(בדיקה: הנגזרת של −1u היא u′u².)

נציב את הגבולות:

S = [−1 / (x² + 2x)] מ-1 עד 4
= −116 + 8 − (−11 + 2)= −124 + 13= −124 + 824= 724

השטח הוא 724 יחידות שטח, בקירוב 0.29.

איפה נופלים בסעיף ד. בסעיף (1) כותבים x > −1 ושוכחים להוציא את x = 0. בסעיף (3) פותחים את הסוגריים במכנה ומנסים לפרק לשברים חלקיים, וזו דרך ארוכה מאוד. מי שמזהה שהמונה הוא הנגזרת של הביטוי שבתוך הריבוע, גומר בשורה אחת.

שאלה 2, שלוש סדרות הנדסיות (20 נקודות)

הנתונים. A סדרה הנדסית אין-סופית a₁, a₂, a₃, .... נתון a₄a₂ = 4 וגם 2a₂ + 8 = a₄. נסמן ב-q את מנת הסדרה.

סעיף א: שתי האפשרויות ל-a₃

בסדרה הנדסית a₄ = a₂ · q², ולכן

a₄ / a₂ = q² = 4
q = 2 או q = −2

את הנתון השני נכתוב בעזרת a₄ = 4a₂:

2a₂ + 8 = 4a₂
8 = 2a₂
a₂ = 4

ומכאן a₃ = a₂ · q:

q= 2: a₃ = 4 · 2 = 8q= −2: a₃ = 4 · (−2) = −8

a₃ = 8 או a₃ = −8.

סעיף ב: הסדרה B הנדסית

איזו מנה? אם q = 2, אז a₁ = a₂q = 2, וכל האיברים חיוביים ומוכפלים ב-2 בכל צעד: 2, 4, 8, 16, .... זו סדרה עולה. אם q = −2, האיברים מחליפים סימן: −2, 4, −8, 16, ..., והסדרה לא עולה ולא יורדת. לכן לפי הנתון

q = −2, a₁ = 4 / (−2) = −2, aₙ = (−2)ⁿ

הוכחה ש-B הנדסית. נתון bₙ = 1 / (aₙ · aₙ₊₁). כל איברי A שונים מאפס, ולכן כל bₙ מוגדר ושונה מאפס. נחשב את היחס בין שני איברים עוקבים:

bₙ₊₁ / bₙ= [1 / (aₙ₊₁ · aₙ₊₂)] / [1 / (aₙ · aₙ₊₁)]= (aₙ · aₙ₊₁) / (aₙ₊₁ · aₙ₊₂)= aₙ / aₙ₊₂

בסדרה הנדסית aₙ₊₂ = aₙ · q², ולכן

bₙ₊₁ / bₙ = 1 / q² = 1 / 4

היחס קבוע ואינו תלוי ב-n. לכן B סדרה הנדסית, והמנה שלה 14.

לשימוש בהמשך: b₁ = 1 / (a₁ · a₂) = 1 / ((−2) · 4) = −18.

סעיף ג: הסדרה C

(1) האיבר ה-m של C בנוי משני איברים עוקבים של A, שהראשון בהם במקום אי-זוגי:

cₘ = k / (a₂ₘ₋₁ · a₂ₘ)

האיבר הבא בנוי משני האיברים ששני מקומות אחריהם: a₂ₘ₊₁ = a₂ₘ₋₁ · q² וגם a₂ₘ₊₂ = a₂ₘ · q². לכן

cₘ₊₁ / cₘ= (a₂ₘ₋₁ · a₂ₘ) / (a₂ₘ₊₁ · a₂ₘ₊₂)= (a₂ₘ₋₁ · a₂ₘ) / (a₂ₘ₋₁ · q² · a₂ₘ · q²)= 1 / q⁴= 1 / 16

מנת הסדרה C היא 116.

(2) האיבר הראשון:

c₁ = k / (a₁ · a₂) = k / ((−2) · 4) = −k8

המנה 116 נמצאת בין 0 ל-1. לכן כל האיברים של C הם בעלי אותו סימן כמו c₁, והערך המוחלט שלהם קטן מאיבר לאיבר.

  • אם c₁ חיובי, האיברים חיוביים וקטנים: הסדרה יורדת.
  • אם c₁ שלילי, האיברים שליליים ומתקרבים ל-0 מלמטה: למשל −16, −1, −116. הסדרה עולה.

לכן C עולה בדיוק כאשר c₁ < 0:

−k8 < 0 ⟺ k > 0

הסדרה C עולה עבור k > 0.

סעיף ד: הערך של k

שתי המנות, 14 ו-116, נמצאות בין −1 ל-1, ולכן לשתי הסדרות יש סכום.

SB = b₁ / (1 − 14) = (−18) / (34) = −16
SC = c₁ / (1 − 116) = (−k8) / (1516) = −k8 · 1615 = −2k15

−2k15 = 4 · (−16) = −23
2k15 = 23
k = 5

k = 5.

שאלה 3, בחירות וסקר טלפוני (20 נקודות)

הנתונים. כל מצביע הצביע למפלגה א' או למפלגה ב'. P היא ההסתברות שמצביע שנבחר באקראי הצביע למפלגה א', ו-0 < P < 1. המדינה גדולה, ולכן בחירות של כמה מצביעים באקראי הן ניסויים בלתי תלויים עם אותה הסתברות P.

סעיף א: הערך של P

בוחרים 3 מצביעים. זו התפלגות בינומית עם n = 3.

P(בדיוק אחד הצביע למפלגה א')= 3 · P · (1 − P)²P(שלושתם הצביעו למפלגה ב')= (1 − P)³

הראשונה גדולה פי 2 מן השנייה:

3P(1 − P)² = 2(1 − P)³

P שונה מ-1, ולכן מותר לחלק ב-(1 − P)²:

3P= 2(1 − P)3P= 2 − 2P5P= 2
P = 0.4

P = 0.4.

סעיף ב: ארבעתם לאותה מפלגה

זו הסתברות מותנית. המאורע "ארבעתם הצביעו לאותה מפלגה" מורכב משני מאורעות זרים: ארבעתם למפלגה א', או ארבעתם למפלגה ב'.

P(ארבעתם למפלגה א')= 0.4⁴ = 0.0256P(ארבעתם למפלגה ב')= 0.6⁴ = 0.1296

ההסתברות המבוקשת היא החלק של "כולם א'" מתוך "כולם אותו דבר":

0.0256 / (0.0256 + 0.1296) = 0.0256 / 0.1552 = 1697 ≈ 0.165

ההסתברות היא 1697, בקירוב 0.165.

סעיף ג: ההסתברות לבחור צעיר

נסמן ב-y את ההסתברות שמצביע שנבחר באקראי הוא צעיר. מן הנתונים:

  • מבין המבוגרים 40% הצביעו למפלגה ב', ולכן 60% הצביעו למפלגה א'.
  • מבין הצעירים 15% הצביעו למפלגה א'.

לפי נוסחת ההסתברות השלמה, ההסתברות להצבעה למפלגה א' היא

P(א') = (1 − y) · 0.6 + y · 0.15

ומסעיף א אנחנו יודעים שהיא 0.4:

0.6 − 0.6y + 0.15y = 0.4
0.6 − 0.45y = 0.4
0.45y = 0.2
y = 0.2 / 0.45 = 49

ההסתברות לבחור צעיר היא 49, בקירוב 0.444.

סעיף ד: חמש שיחות בדיוק

דני מתקשר לצעירים בלבד. אצלם ההסתברות להצבעה למפלגה א' היא 0.15, ולמפלגה ב' היא 0.85. הוא מפסיק ברגע שיש לו צעיר אחד מכל מפלגה.

מתי הוא מפסיק בדיוק בשיחה החמישית? כאשר ארבעת הצעירים הראשונים הצביעו כולם לאותה מפלגה (אחרת היה מפסיק קודם), והחמישי הצביע למפלגה האחרת. יש שתי אפשרויות זרות:

ארבעה למפלגה א', ואז אחד למפלגה ב': 0.15⁴ · 0.85 = 0.0004303125
ארבעה למפלגה ב', ואז אחד למפלגה א': 0.85⁴ · 0.15 = 0.0783009375

ונחבר:

0.0004303125 + 0.0783009375 = 0.07873125

ההסתברות היא 0.07873125, בקירוב 0.0787.

שאלה 4, שני מעגלים ומשיק (20 נקודות)

הנתונים. מעגל גדול שרדיוסו R, ומעגל קטן שמרכזו O ורדיוסו r. הנקודה O נמצאת על המעגל הגדול. A היא נקודת חיתוך של שני המעגלים. המשיק למעגל הקטן בנקודה A חותך את המעגל הגדול בנקודה K. הנקודה E על המעגל הקטן, בתוך המשולש KAO.

סעיף א: ∢AOE = 2∢KAE

  • OA רדיוס של המעגל הקטן, ו-AK משיק לו בנקודה A. רדיוס לנקודת ההשקה מאונך למשיק, ולכן ∢KAO = 90°.
  • OA ו-OE שניהם רדיוסים של המעגל הקטן, ולכן המשולש AOE שווה שוקיים, וזוויות הבסיס שלו שוות:
∢OAE = ∢OEA = (180° − ∢AOE) / 2 = 90° − ½∢AOE
  • הנקודה E בתוך המשולש KAO, ולכן הקרן AE עוברת בתוך הזווית KAO ומחלקת אותה לשתיים:
∢KAE = ∢KAO − ∢OAE = 90° − (90° − ½∢AOE) = ½∢AOE

ומכאן ∢AOE = 2∢KAE.

(זה המקרה הפרטי של המשפט על זווית בין משיק למיתר: היא שווה למחצית הזווית המרכזית הנשענת על אותו מיתר.)

סעיף ב: M מרכז המעגל הגדול

הנקודות K, A, O שלושתן על המעגל הגדול, ולכן ∢KAO היא זווית היקפית בו. מסעיף א ∢KAO = 90°. זווית היקפית בת 90° נשענת על קוטר, ולכן OK קוטר של המעגל הגדול.

מרכז המעגל הוא אמצע כל קוטר. M היא אמצע OK, ולכן M היא מרכז המעגל הגדול.

סעיף ג: △MOA ∼ △OEA

  • M מרכז המעגל הגדול, ו-MO ו-MA רדיוסים שלו. לכן MO = MA = R, והמשולש MOA שווה שוקיים: ∢MOA = ∢MAO.
  • OE = OA = r, ולכן המשולש OEA שווה שוקיים: ∢OEA = ∢OAE.
  • הנקודות A, E, M על ישר אחד (M על המשך AE), ולכן ∢MAO ו-∢EAO הן אותה זווית.

נסמן אותה ב-β. בשני המשולשים יש שתי זוויות בנות β:

במשולש MOA: ∢MAO = β, ∢MOA = β
במשולש OEA: ∢EAO = β, ∢OEA = β

שתי זוויות שוות, ולכן △MOA ∼ △OEA לפי ז.ז. ההתאמה היא M↔O, O↔E, A↔A (קודקוד הראש של כל משולש מול קודקוד הראש של השני), ומכאן

MOOE = OAEA = MAOA

סעיף ד: שטח המשולש OKA

נתון R = 1.5r, ו-S הוא שטח המשולש MEO.

שלב 1: אורכים על הישר AM. יחס הדמיון מסעיף ג הוא MOOE = Rr = 1.5. לכן

OA / EA = 1.5 ⟹ EA = r / 1.5 = 2r3
MA= R = 1.5r = 3r2ME= MA − EA = 3r2 − 2r3 = 9r6 − 4r6 = 5r6

שלב 2: מן המשולש MEO למשולש MAO. לשני המשולשים קודקוד משותף O, והבסיסים שלהם, ME ו-MA, מונחים על אותו ישר. לכן יש להם אותו גובה מ-O, ויחס השטחים שווה ליחס הבסיסים:

SMEO / SMAO = ME / MA = (5r6) / (3r2) = 59
SMAO = 9S5

שלב 3: מן המשולש MAO למשולש OKA. M אמצע הצלע OK, ולכן AM תיכון במשולש OKA. תיכון מחלק משולש לשני משולשים שווי שטח:

SOKA = 2 · SMAO = 2 · 9S5 = 18S5

שטח המשולש OKA הוא 18S5, כלומר 3.6S.

בדיקה בדרך אחרת: יחס השטחים של משולשים דומים הוא ריבוע יחס הדמיון, ולכן SOEA = SMOA / 1.5² = 49 · SMOA. המשולש MEO הוא מה שנשאר מ-MOA אחרי שמורידים את OEA, ולכן S = (1 − 49) · SMOA = 59 · SMOA. אותה תוצאה.

איפה נופלים בשאלה 4. בסעיף ב מנסים להשתמש ב-E ובסעיף א, ואין בהם צורך: הזווית הישרה מספיקה. בסעיף ג כותבים את ההתאמה בסדר הלא נכון (M↔E), ואז היחסים בסעיף ד יוצאים הפוכים. בסעיף ד שוכחים שגם EA וגם MA יושבים על אותו ישר, ומחשבים את ME כסכום במקום כהפרש.

שאלה 5, מעגל חסום במשולש שווה שוקיים (20 נקודות)

הנתונים. במשולש ABC, AC = AB, חסום מעגל שמרכזו O ורדיוסו r. נסמן ∢ACB = 2α. כיוון ש-2α היא זווית בסיס במשולש שווה שוקיים, היא חדה: 0° < α < 45°.

נסמן ב-D את נקודת ההשקה של המעגל עם הבסיס CB. במשולש שווה שוקיים הגובה מן הקודקוד A הוא גם חוצה הזווית, ולכן הוא עובר דרך O ופוגש את CB באמצעו, בנקודה D. בסרטוט זה הקטע האנכי AO.

סעיף א: CO ו-AC

(1) מרכז המעגל החסום נמצא על חוצי הזוויות, ולכן CO חוצה את הזווית C: ∢OCD = α. הרדיוס לנקודת ההשקה מאונך לצלע, ולכן במשולש ODC הזווית D ישרה ו-OD = r.

sin α = OD / CO = r / CO

CO = r / sin α.

(2) באותו משולש ODC:

tan α = OD / CD ⟹ CD = r / tan α

במשולש ADC הזווית D ישרה והזווית C היא 2α:

cos 2α = CD / AC ⟹ AC = CD / cos 2α

AC = r / (tan α · cos 2α), ובצורה אחרת AC = r · cos α / (sin α · cos 2α).

סעיף ב: הערך של α

נתון AC = √3 · CO:

r / (tan α · cos 2α) = √3 · r / sin α

נחלק ב-r ונכפול ב-sin α. כיוון ש-sin α / tan α = cos α:

cos α / cos 2α = √3
cos α = √3 · cos 2α = √3 · (2cos²α − 1)
2√3 cos²α − cos α − √3 = 0

זו משוואה ריבועית ב-cos α:

cos α= [1 ± √1 + 4 · 2√3 · √3] / (2 · 2√3)= [1 ± √25] / (4√3)= (1 ± 5) / (4√3)
cos α = 64√3 = √32 או cos α = −44√3 = −1√3

α חדה, ולכן הפתרון השלילי נפסל. cos α = √32, ולכן α = 30°.

(שימו לב למה זה אומר: ∢ACB = 60°, וזווית הבסיס של משולש שווה שוקיים היא 60° רק כשהמשולש שווה צלעות.)

סעיף ג: הערך של r

מציבים α = 30°. מסעיף א(1):

CO = r / sin 30° = 2r

המשולש שווה צלעות, ולכן גם BO = 2r, וגם ∢OBC = 30°. במשולש COB

∢COB = 180° − 30° − 30° = 120°

הנקודה K על הקטע BO ועל המעגל, ולכן OK = r. במשולש COK ידועות שתי צלעות והזווית שביניהן, ונשתמש במשפט הקוסינוסים:

CK²= CO² + OK² − 2 · CO · OK · cos 120°= 4r² + r² − 2 · 2r · r · (−½)= 4r² + r² + 2r²= 7r²

נציב CK = √175:

7r² = 175
r² = 25
r = 5

r = 5.

סעיף ד: אורך BE

אורך הבסיס. מסעיף א(2), CD = r / tan 30° = 5 / (1√3) = 5√3, ולכן

CB = 2 · CD = 10√3 ≈ 17.32

הגובה של K מעל CB. BO = 2r = 10 ו-OK = r = 5, ולכן BK = 5: הנקודה K היא אמצע BO. במשולש ישר הזווית שהגובה של K יוצר עם CB:

h = BK · sin∢KBC = 5 · sin 30° = 2.5

(אותה תוצאה: O נמצאת בגובה r = 5 מעל CB, B בגובה 0, ו-K באמצע ביניהן.)

הצלע CE. הבסיס CE של המשולש CKE מונח על CB, והגובה אליו הוא h:

½ · CE · 2.5 = 18
CE = 36 / 2.5 = 14.4

CE = 14.4 קטן מ-CB ≈ 17.32, ולכן E אכן נמצאת על הצלע. ומכאן

BE = CB − CE = 10√3 − 14.4 ≈ 2.92

BE = 10√3 − 14.4, בקירוב 2.92.

איפה נופלים בשאלה 5. בסעיף א(2) מחלקים בסינוס במקום בקוסינוס, או לוקחים את הזווית α במקום 2α במשולש ADC. בסעיף ג מניחים ש-K היא נקודת ההשקה, ומקבלים משולש ישר זווית שאינו קיים. K היא החיתוך של המעגל עם BO, ולכן OK = r. בסעיף ד שוכחים לחשב את הגובה של K, ומשתמשים בגובה של O.

שאלה 6, פונקצייה עם שורש ופרמטר (20 נקודות)

הנתונים. f(x) = x / √x² − a², ו-a פרמטר חיובי.

סעיף א: תחום הגדרה ואסימפטוטות

(1) הביטוי שמתחת לשורש צריך להיות אי-שלילי, והשורש נמצא במכנה, ולכן הוא אינו יכול להיות אפס. לכן הביטוי חייב להיות חיובי ממש:

x² − a² > 0 ⟺ x² > a² ⟺ |x| > a

תחום ההגדרה: x < −a או x > a.

(2) אסימפטוטות אנכיות. המכנה מתאפס בקצוות התחום, x = a ו-x = −a, והמונה שם אינו אפס:

כש-x שואף ל-a מימין: המונה שואף ל-a > 0, המכנה ל-0 מלמעלה, ו-f שואפת לפלוס אינסוף
כש-x שואף ל-(−a) משמאל: המונה שואף ל-(−a) < 0, ו-f שואפת למינוס אינסוף

אסימפטוטות אופקיות. נוציא x² מתוך השורש: √x² − a² = |x| · √1 − a²x². לכן

f(x) = x / (|x| · √1 − a²x²)

כש-x חיובי וגדול, x/|x| = 1, והשורש שואף ל-1, ולכן f שואפת ל-1. כש-x שלילי, x/|x| = −1, ולכן f שואפת ל-(−1).

האסימפטוטות: x = a, x = −a (אנכיות), y = 1 כש-x שואף לאינסוף, ו-y = −1 כש-x שואף למינוס אינסוף (אופקיות).

סעיף ב: f אי-זוגית

תחום ההגדרה סימטרי סביב 0: אם x בתחום, גם −x בתחום. ולכל x בתחום

f(−x) = (−x) / √(−x)² − a² = −x / √x² − a² = −f(x)

לכן f פונקצייה אי-זוגית.

סעיף ג: עלייה וירידה

נגזור לפי כלל המנה. הנגזרת של √x² − a² היא x / √x² − a²:

f′(x) = [1 · √x² − a² − x · x√x² − a²] / (x² − a²)

נכפול מונה ומכנה ב-√x² − a²:

f′(x) = [(x² − a²) − x²] / (x² − a²)3/2 = −a² / (x² − a²)3/2

המונה −a² שלילי (a > 0), והמכנה חיובי בכל התחום. לכן f′(x) < 0 לכל x בתחום.

f יורדת בתחום x < −a ובתחום x > a, ואין לה תחומי עלייה (ולכן גם אין לה נקודות קיצון).

סעיף ד: סקיצה

נאסוף את מה שמצאנו:

  • אין גרף בין x = −a ל-x = a.
  • 0 אינו בתחום, ו-f(x) ≠ 0 בתחום (המונה x שונה מאפס), ולכן אין חיתוך עם הצירים.
  • הענף הימני (x > a): יורד מפלוס אינסוף ליד x = a, ומתקרב ל-y = 1. הוא מתקרב מלמעלה, כי שם f(x) = 1√1 − a²x² > 1.
  • הענף השמאלי (x < −a): f אי-זוגית, ולכן הוא תמונת ראי של הענף הימני סביב ראשית הצירים. הוא מתחיל ליד y = −1 (מתחתיו) כש-x שואף למינוס אינסוף, ויורד למינוס אינסוף כש-x מתקרב ל-(−a).

סעיף ה: הפונקצייה g

(1) נפשט קודם. f² = x² / (x² − a²), ולכן

g(x) = 1 / f(x)² = (x² − a²) / x² = 1 − a²x²

בתחום x < −a או x > a. עכשיו הגזירה קלה:

g′(x) = 2a² / x³

סימן הנגזרת הוא סימן x³, כלומר סימן x:

x > a: g′(x) > 0, g עולה
x < −a: g′(x) < 0, g יורדת

g יורדת בתחום x < −a ועולה בתחום x > a.

(2) נבדוק מה מאפיין את g:

  • תחום: אין גרף בין −a ל-a. גרף III מוגדר עד ממש ליד ציר ה-y. נפסל.
  • התנהגות בקצוות התחום: כש-x מתקרב ל-a או ל-(−a), g(x) שואפת ל-1 − 1 = 0. הגרף מגיע לנקודות (a , 0) ו-(−a , 0), שאינן שייכות לו (עיגולים ריקים), ואין אסימפטוטות אנכיות. גרף II, עם האסימפטוטות האנכיות, נפסל.
  • סימטרייה: g(−x) = g(x), כלומר g זוגית והגרף סימטרי סביב ציר ה-y. בגרף IV העיגול הימני גבוה מן השמאלי. נפסל.

גרף I מתאר את g(x): הענף השמאלי יורד אל עיגול ריק על ציר ה-x, הענף הימני עולה מעיגול ריק על ציר ה-x, ושניהם מתקרבים ל-y = 1 מלמטה, כי a²x² > 0.

הנתונים. f(x) = a(x − 1)² + 9, בתחום x ≠ 1, ו-a פרמטר חיובי.

סעיף א: אסימפטוטות

אנכית: המכנה מתאפס ב-x = 1, והמונה a שונה מאפס. כיוון ש-(x − 1)² חיובי ו-a > 0, הפונקצייה שואפת לפלוס אינסוף משני הצדדים.

השאלות שהפתרון עונה עליהן הן מן השאלון של משרד החינוך, המנהל הפדגוגי, אגף בכיר בחינות, והזכויות בו שמורות למדינת ישראל. השאלון עצמו אינו מועתק לדף הזה: הוא נפתח מדף הבחינה, שמקושר בראש הדף.

זכות היוצרים שמורה למדינת ישראל

אין להעתיק או לפרסם אלא ברשות משרד החינוך

ההודעה מודפסת בעמוד האחרון של השאלון ושל הצעת הפתרון. מצוטטת כאן מילה במילה.

הדף הזה אינו מסמך רשמי של משרד החינוך, ואינו מאושר על ידו.
