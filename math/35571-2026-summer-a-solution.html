לפני שמתחילים

זה השאלון הראשון של 5 יחידות לימוד בתוכנית החדשה. יש בו שמונה שאלות בארבעה פרקים: שאלות קצרות (שאלה 1), אינדוקצייה, סדרות והסתברות (שאלות 2 ו-3), גאומטרייה וטריגונומטרייה במישור (שאלות 4 ו-5), וחשבון דיפרנציאלי ואינטגרלי (שאלות 6 עד 8).

עונים על חמש שאלות: לפחות על שאלה אחת מן הפרק הראשון או השני, ולפחות על שאלה אחת מכל אחד מן הפרקים השלישי והרביעי. כל שאלה שווה 20 נקודות, וחמש שאלות הן 100 נקודות. מי שעונה על יותר מחמש שאלות, נבדקות לו רק חמש התשובות הראשונות שבמחברת. בשאלה 1 עונים על שניים מארבעת הסעיפים א עד ד, וגם שם נבדקות רק שתי התשובות הראשונות. השאלון אינו מפרט ניקוד לתת-סעיפים.

משך הבחינה שלוש שעות וארבעים וחמש דקות. מותרים מחשבון לא גרפי ודפי הנוסחאות המצורפים.

כאן פתורות כל שמונה השאלות, ובשאלה 1 כל ארבעת הסעיפים, כדי שכל בחירה אפשרית של תלמיד תהיה מכוסה. בכל שאלה מופיעים הנתונים, השלבים והנימוק לכל שלב, ובסופה הערה קצרה על המקום שבו נופלים.

שאלה 1, ארבעה סעיפים קצרים (20 נקודות)

עונים על שניים מן הסעיפים. כל סעיף כאן עומד בפני עצמו.

סעיף א: אינדוקצייה על סכום של שברים

צריך להוכיח שלכל n טבעי

1²1 · 3 + 2²3 · 5 + ... + n²(2n − 1)(2n + 1) = n(n + 1) / (2(2n + 1))

נבין קודם איך הסכום בנוי. האיבר שבמקום k הוא k²(2k − 1)(2k + 1): במונה ריבוע של מספר המקום, ובמכנה שני האי-זוגיים שמשני צדי 2k. כשנוסיף איבר, נציב k = n + 1 ונקבל (n + 1)²(2n + 1)(2n + 3).

בדיקה עבור n = 1. באגף שמאל יש איבר אחד בלבד, 11 · 3 = 13. באגף ימין 1 · 2 / (2 · 3) = 26 = 13. הטענה נכונה.

הנחת האינדוקצייה. נניח שעבור n טבעי מסוים מתקיים

1²1 · 3 + ... + n²(2n − 1)(2n + 1) = n(n + 1) / (2(2n + 1))

צריך להוכיח את הטענה עבור n + 1, כלומר

1²1 · 3 + ... + n²(2n − 1)(2n + 1) + (n + 1)²(2n + 1)(2n + 3) = (n + 1)(n + 2) / (2(2n + 3))

ההוכחה. נחליף את כל האיברים עד המקום n לפי ההנחה. בשני השברים שנשארו יש גורם משותף, n + 12n + 1, ונוציא אותו:

n(n + 1)2(2n + 1) + (n + 1)²(2n + 1)(2n + 3)
= n + 12n + 1 · [ n2 + n + 12n + 3 ]= n + 12n + 1 · [ n(2n + 3) + 2(n + 1) ] / (2(2n + 3))= n + 12n + 1 · (2n² + 5n + 2) / (2(2n + 3))

עכשיו הרגע החשוב: מפרקים את 2n² + 5n + 2. שורשי המשוואה 2n² + 5n + 2 = 0 הם n = −2 ו-n = −½, ולכן

2n² + 5n + 2 = (2n + 1)(n + 2)

הגורם 2n + 1 מצטמצם עם המכנה:

= n + 12n + 1 · (2n + 1)(n + 2) / (2(2n + 3))= (n + 1)(n + 2) / (2(2n + 3))

קיבלנו בדיוק את אגף ימין עבור n + 1, כי 2(n + 1) + 1 = 2n + 3. לפי עקרון האינדוקצייה, השוויון מתקיים לכל n טבעי.

סעיף ב: הספרים של יונתן

הנתונים. 60% מן הספרים הם ספרי קומיקס ו-40% ספרי עיון. 70% מן הספרים בעברית ו-30% באנגלית. נסמן ב-p את החלק של הספרים שהם גם קומיקס וגם בעברית.

טענה I: ליונתן אין ספרי קומיקס בעברית.

נחשוב על כל הספרים כעל 100%. ספרי הקומיקס תופסים 60% וספרי העברית 70%. אם שתי הקבוצות היו זרות, הן היו תופסות יחד 130%, ואין דבר כזה. כלומר הקבוצות חייבות לחפוף, והחפיפה היא לפחות

p ≥ 60% + 70% − 100% = 30%

אותה מסקנה בדרך אחרת: יש רק 40% ספרי עיון, ולכן גם אם כל ספרי העיון בעברית, נשארים לפחות 70% − 40% = 30% ספרים בעברית שאינם ספרי עיון, והם ספרי קומיקס.

הטענה לא נכונה. לפחות 30% מן הספרים הם ספרי קומיקס בעברית.

טענה II: P(עברית | קומיקס) גדולה מ-P(קומיקס | עברית).

שתי ההסתברויות המותנות בנויות מאותו מונה, החלק המשותף p, ומכנה שונה:

P(עברית | קומיקס)= p / 0.6P(קומיקס | עברית)= p / 0.7

מטענה I אנחנו יודעים ש-p > 0 (בעצם p ≥ 0.3). כשמחלקים אותו מספר חיובי במספר קטן יותר, מקבלים תוצאה גדולה יותר, ו-0.6 < 0.7.

הטענה נכונה.

סעיף ג: הפונקצייה g(x) = 1(f(x))²

הנתונים מן הגרף. f מוגדרת לכל x. יש לה אסימפטוטה אחת בלבד, y = 0, והגרף מתקרב אליה משני הצדדים: משמאל מלמעלה ומימין מלמטה. נקודת החיתוך היחידה עם ציר ה-x היא (12 , 0). נקודות הקיצון: מקסימום (6 , a) ומינימום (18 , −2a), ו-a > 1.

נרשום את תחומי העלייה והירידה ואת הסימן של f, כי ממנו נבנה הכול:

x < 6: f עולה, f > 0
6 < x < 12: f יורדת, f > 0
12 < x < 18: f יורדת, f < 0
x > 18: f עולה, f < 0

(1) תחום ההגדרה. אסור שהמכנה (f(x))² יתאפס, כלומר אסור ש-f(x) = 0. הדבר קורה רק ב-x = 12, ולכן

תחום ההגדרה של g הוא x ≠ 12.

(2) סקיצה. נאסוף את התכונות של g אחת אחת.

סימן. (f(x))² > 0 בכל התחום, ולכן g(x) > 0 תמיד. הגרף כולו מעל ציר ה-x.

אסימפטוטות. כש-x מתקרב ל-12, f(x) מתקרבת ל-0, ולכן 1(f(x))² שואפת ל-∞. זו אסימפטוטה אנכית x = 12. כש-x → ∞ או x → −∞, גם אז f(x) → 0, ולכן g(x) → ∞. אין ל-g אסימפטוטה אופקית.

עלייה, ירידה וקיצון. לפי כלל השרשרת

g(x) = (f(x))−2
g′(x) = −2 · f′(x) / (f(x))³

הסימן של g′ הפוך לסימן של f′ במקום שבו f חיובית, וזהה לו במקום שבו f שלילית:

x < 6: f′ > 0, f > 0 ⇒ g′ < 0, g יורדת
6 < x < 12: f′ < 0, f > 0 ⇒ g′ > 0, g עולה
12 < x < 18: f′ < 0, f < 0 ⇒ g′ < 0, g יורדת
x > 18: f′ > 0, f < 0 ⇒ g′ > 0, g עולה

ההיגיון מאחורי הטבלה פשוט: g גדולה כש-|f| קטן, וקטנה כש-|f| גדול. במקום שבו |f| מגיע לשיא, ל-g יש שפל. לכן שתי נקודות הקיצון של f הופכות לשתי נקודות מינימום של g:

g(6)= 1a²g(18)= 1(−2a)² = 14a²

תיאור הסקיצה. משמאל לאסימפטוטה x = 12: הגרף יורד מ-∞ עד המינימום (6 , 1a²), ואז עולה ל-∞ כש-x מתקרב ל-12. מימין לאסימפטוטה: הגרף יורד מ-∞ עד המינימום (18 , 14a²), ואז עולה ל-∞. שתי "קערות" מעל ציר ה-x, והקערה הימנית יורדת נמוך יותר, כי 14a² < 1a².

(3) הערך של a. הישר y = a27 אופקי. נספור כמה פעמים ישר אופקי y = c חותך כל קערה:

הקערה השמאלית (מינימום 1a²): c > 1a² שתי נקודות, c = 1a² נקודה אחת, c < 1a² אף לא אחת
הקערה הימנית (מינימום 14a²): c > 14a² שתי נקודות, c = 14a² נקודה אחת, c < 14a² אף לא אחת

כדי לקבל בדיוק 3 נקודות צריך 1 + 2. האפשרות היחידה: הישר משיק לקערה השמאלית, כלומר עובר בדיוק בגובה המינימום שלה, וכך הוא בהכרח גבוה מן המינימום של הקערה הימנית וחותך אותה פעמיים. (אם הישר בגובה 14a², הוא נוגע בקערה הימנית בלבד, ויש נקודה אחת.)

a27 = 1a²
a³ = 27
a = 3

התוצאה מקיימת a > 1. a = 3.

סעיף ד: מן f אל g, וזיהוי הגרף

הנתונים. f(x) = −30x² / (x³ − 8)², בתחום x ≠ 2. נתון ש-g′(x) = f(x), ש-g מוגדרת בתחום x ≠ 2, ושהגרף של g עובר דרך (0 , 0.75).

(1) מציאת g. צריך פונקצייה קדומה של f. שימו לב שבמונה יש x², וזו בדיוק הנגזרת של x³ (עד כדי פי 3). זה סימן להציב u = x³ − 8:

u = x³ − 8, du = 3x² dx, x² dx = du3
∫ −30x² / (x³ − 8)² dx = ∫ −10 / u² du = 10u + C = 10x³ − 8 + C

בדיקה בגזירה: (10 · (x³ − 8)−1)′ = −10 · 3x² / (x³ − 8)² = −30x² / (x³ − 8)². נכון.

נציב את הנקודה (0 , 0.75):

100 − 8 + C = 0.75
−1.25 + C = 0.75
C = 2

g(x) = 10x³ − 8 + 2.

הערה קטנה לתלמיד המדויק: התחום x ≠ 2 בנוי משני קטעים נפרדים, והנקודה (0 , 0.75) קובעת את הקבוע רק בקטע x < 2. השאלה מבקשת פונקצייה המקיימת את התנאים, ולכן מותר לבחור את אותו קבוע גם בקטע השני, וזו הבחירה הטבעית.

(2) איזה גרף. נאסוף מה ידוע על g:

  • g יורדת בכל אחד מתחומי ההגדרה. g′(x) = f(x) = −30x²(x³ − 8)², ובשבר הזה המונה x² ≥ 0 והמכנה ריבוע חיובי. לכן f(x) ≤ 0 בכל התחום, ומתאפסת רק ב-x = 0. גם בגרף של f רואים זאת: הוא כולו מתחת לציר ה-x או עליו.
  • משיק אופקי ב-x = 0. g′(0) = f(0) = 0. זו לא נקודת קיצון, כי g′ לא מחליפה סימן שם (שלילית משני הצדדים), אלא נקודה שבה הגרף "מתיישר" לרגע וממשיך לרדת.
  • הנקודה (0 , 0.75) נמצאת מעל ציר ה-x.
  • אסימפטוטות. x = 2 אנכית: משמאל g → −∞ (המכנה x³ − 8 קטן ושלילי), ומימין g → +∞. y = 2 אופקית, כי 10x³ − 8 → 0 כש-x → ±∞. משמאל הגרף מתקרב ל-2 מלמטה, ומימין מלמעלה.
  • חיתוך עם ציר ה-x. 10x³ − 8 = −2 נותן x³ = 3, כלומר x = ∛3 ≈ 1.44, בין ציר ה-y לבין האסימפטוטה.

עכשיו נעבור על הגרפים:

  • גרף IV עולה לאורך כל התחום. נפסל, כי g יורדת.
  • גרף III עולה בחלק השמאלי, ליד האסימפטוטה האנכית, ויש לו שם מינימום. נפסל מאותה סיבה.
  • גרף II יורד, אבל בנקודה שבה הוא חוצה את ציר ה-y השיפוע שלו שלילי בבירור, ואין בה משיק אופקי. נפסל, כי g′(0) = 0.
  • גרף I יורד בשני הקטעים, "מתיישר" בדיוק על ציר ה-y מעל ציר ה-x, חוצה את ציר ה-x לפני האסימפטוטה האנכית ומתקרב לאסימפטוטה האופקית משני צדדיה כמו שחישבנו.

התשובה: גרף I.

איפה נופלים בשאלה 1. בסעיף א, מי שלא מוציא גורם משותף לפני שהוא מכנס את השברים נתקע עם מכנה ענק. החוכמה היא להוציא את n + 12n + 1 מיד, ואחר כך לפרק את 2n² + 5n + 2. בסעיף ג, טעות נפוצה היא לחשוב שהמקסימום של f נשאר מקסימום של g. הפוך: 1f² מחליפה גבוה בנמוך. ועוד טעות: לשכוח ש-g שואפת ל-∞ גם בקצוות, ולכן אין לה אסימפטוטה אופקית. בסעיף ד, נקודה שבה g′ = 0 אינה בהכרח קיצון. כאן היא נקודת פיתול עם משיק אופקי.

פרק שני: אינדוקצייה, סדרות והסתברות

שאלה 2, שלוש סדרות הנדסיות (20 נקודות)

הנתונים. a(n) סדרה הנדסית אין-סופית עולה שמנתה q. b(n) סדרה הנדסית אין-סופית עולה שמנתה 2q. הסדרה c(n) מוגדרת על ידי c(n) = a(n) · b(n).

סעיף א: c(n) הנדסית

סדרה היא הנדסית אם המנה בין כל איבר לקודמו קבועה. נחשב את המנה הזאת עבור c(n):

c(n+1) / c(n)= [a(n+1) · b(n+1)] / [a(n) · b(n)]= [a(n+1) / a(n)] · [b(n+1) / b(n)]= q · 2q= 2q²

(אין כאן חלוקה באפס: בסדרה הנדסית אין איבר שווה אפס.) המנה אינה תלויה ב-n, ולכן c(n) היא סדרה הנדסית, ומנתה 2q².

סעיף ב: הערך של q

נתון: a₁ = b₁ ו-c₂ = (18) · (a₁)².

נבטא את c₂ באמצעות a₁ ו-q:

c₂ = a₂ · b₂ = (a₁ · q) · (b₁ · 2q) = (a₁ · q) · (a₁ · 2q) = 2q² · a₁²

נשווה לנתון. a₁ ≠ 0, ולכן מותר לחלק ב-a₁²:

2q² · a₁² = a₁² / 8
q² = 116
q = 14 או q = −14

נפסול את q = −14. בסדרה הנדסית עם מנה שלילית הסימנים של האיברים מתחלפים: חיובי, שלילי, חיובי וכן הלאה. סדרה כזאת קופצת למעלה ולמטה, ואינה יכולה להיות עולה. נתון שהסדרות עולות, ולכן

q = 14.

מכאן מנת b(n) היא 2q = 12, ומנת c(n) היא 2q² = 18.

סעיף ג: סימן ומגמה

(1) הסימן של a₁. נבדוק את ההפרש בין שני איברים עוקבים:

a(n+1) − a(n) = a(n) · q − a(n) = a(n) · (q − 1) = a(n) · (−34)

הנתונים. f(x) = ax / (x − 3)², בתחום x ≠ 3, ו-a פרמטר חיובי.

סעיף א: אסימפטוטות וקיצון

(1) אסימפטוטות המאונכות לצירים.

אנכית. המכנה מתאפס ב-x = 3, והמונה שם שווה 3a ≠ 0. לכן x = 3 אסימפטוטה אנכית.

אופקית. מעלת המונה 1 קטנה ממעלת המכנה 2, ולכן f(x) → 0 כש-x → ±∞. לכן y = 0 אסימפטוטה אופקית.

(2) נקודת הקיצון. נגזור לפי כלל המנה, ונוציא את (x − 3) מן המונה כדי לצמצם:

f′(x)= [a(x − 3)² − ax · 2(x − 3)] / (x − 3)⁴= a(x − 3)[(x − 3) − 2x] / (x − 3)⁴= a(−x − 3) / (x − 3)³= −a(x + 3) / (x − 3)³

f′(x) = 0 רק כאשר x = −3. נבדוק את סימן הנגזרת (a > 0):

x < −3: x + 3 < 0, (x − 3)³ < 0 ⇒ f′ < 0, יורדת
−3 < x < 3: x + 3 > 0, (x − 3)³ < 0 ⇒ f′ > 0, עולה
x > 3: x + 3 > 0, (x − 3)³ > 0 ⇒ f′ < 0, יורדת

ב-x = −3 הנגזרת עוברת משלילית לחיובית, ולכן זה מינימום:

f(−3) = −3a / (−6)² = −3a36 = −a12

נקודת מינימום (−3 , −a12).

סעיף ב: סקיצה

נוסיף נקודת חיתוך: f(x) = 0 רק כאשר x = 0, ולכן הגרף חותך את הצירים רק בראשית (0 , 0). סימן: המכנה תמיד חיובי, ולכן f שלילית עבור x < 0 וחיובית עבור x > 0 (x ≠ 3).

תיאור הסקיצה:

  • משמאל, כש-x → −∞, הגרף מתקרב לאסימפטוטה y = 0 מלמטה.
  • הוא יורד עד המינימום (−3 , −a12).
  • עולה, עובר בראשית, וממשיך לעלות ל-+∞ כש-x מתקרב ל-3 משמאל.
  • מימין ל-x = 3 הוא יורד מ-+∞, ומתקרב ל-y = 0 מלמעלה כש-x → ∞.

סעיף ג: הערך של a

g(x) = f(x) + 0.5 היא הזזה של f חצי יחידה כלפי מעלה. g(x) = 0 פירושו f(x) = −0.5. כלומר צריך שהישר y = −0.5 יפגוש את הגרף של f בדיוק פעם אחת.

מן הסקיצה: f מקבלת ערכים שליליים רק בתחום x < 0, ושם הערך הנמוך ביותר הוא המינימום −a12. משמאל ל-−3 הגרף יורד מ-0 ל-−a12, ומימין ל-−3 הוא עולה מ-−a12 בחזרה ל-0. ישר אופקי שלילי y = c:

c < −a12: אין נקודות משותפות
c = −a12: נקודה אחת, המינימום עצמו
−a12 < c < 0: שתי נקודות, אחת בכל צד של −3

לכן צריך ש-y = −0.5 יעבור בדיוק דרך המינימום:

−a12 = −0.5
a = 6

בדיקה אלגברית: ax(x − 3)² = −12 נותן x² + (2a − 6)x + 9 = 0. עבור a = 6 זה x² + 6x + 9 = (x + 3)² = 0, ופתרון יחיד x = −3. נכון.

a = 6.

סעיף ד: הפונקצייה h(x) = g(x) · g′(x)

נציב a = 6. קודם נפשט את g, כי יש פה הפתעה נעימה:

g(x)= 6x(x − 3)² + 12= [12x + (x − 3)²] / (2(x − 3)²)= (x² + 6x + 9) / (2(x − 3)²)= (x + 3)² / (2(x − 3)²)

וזה מסתדר עם סעיף ג: g נוגעת בציר ה-x בנקודה אחת, x = −3, וחיובית בכל מקום אחר. הנגזרת של g זהה לזו של f, כי הוספת קבוע לא משנה נגזרת:

g′(x) = f′(x) = −6(x + 3) / (x − 3)³

(1) תחומי חיוביות ושליליות.

h(x) = (x + 3)² / (2(x − 3)²) · (−6(x + 3)) / (x − 3)³ = −3(x + 3)³ / (x − 3)⁵

חזקה אי-זוגית שומרת על הסימן: הסימן של (x + 3)³ הוא הסימן של x + 3, והסימן של (x − 3)⁵ הוא הסימן של x − 3. בגלל המקדם −3, h חיובית בדיוק כשהמנה x + 3x − 3 שלילית:

x < −3: x + 3 < 0, x − 3 < 0 ⇒ x + 3x − 3 > 0 ⇒ h < 0
−3 < x < 3: x + 3 > 0, x − 3 < 0 ⇒ x + 3x − 3 < 0 ⇒ h > 0
x > 3: x + 3 > 0, x − 3 > 0 ⇒ x + 3x − 3 > 0 ⇒ h < 0

h חיובית בתחום −3 < x < 3, ושלילית בתחומים x < −3 ו-x > 3. ב-x = −3 היא מתאפסת.

אפשר להגיע לאותה תוצאה בלי לפשט: g(x) ≥ 0 תמיד, ולכן הסימן של h הוא הסימן של g′, כלומר h חיובית בדיוק במקום שבו g עולה (−3 < x < 3) ושלילית במקום שבו g יורדת.

(2) השטח בתחום −9 ≤ x ≤ 0.

הטריק: h = g · g′ היא בדיוק הנגזרת של ½g², לפי כלל השרשרת:

(½ g(x)²)′ = ½ · 2g(x) · g′(x) = g(x) · g′(x) = h(x)

לכן ½g² היא פונקצייה קדומה של h, ואין צורך לפתח שום שבר.

h מחליפה סימן ב-x = −3, ולכן מחלקים את התחום לשניים. נחשב את ערכי g בנקודות הרלוונטיות:

g(−9)= (−6)² / (2 · (−12)²) = 36288 = 18g(−3)= 0g(0)= 3² / (2 · (−3)²) = 918 = 12

בתחום −9 ≤ x ≤ −3: h שלילית, ולכן השטח הוא מינוס האינטגרל:

S₁ = −∫ h dx (מ-−9 עד −3) = −[½g²] = −(½ · 0² − ½ · (18)²) = 1128

בתחום −3 ≤ x ≤ 0: h חיובית:

S₂ = ∫ h dx (מ-−3 עד 0) = ½ · (12)² − ½ · 0² = 18
S = S₁ + S₂ = 1128 + 16128 = 17128

השטח הוא 17128 ≈ 0.133 יחידות שטח.

איפה נופלים בשאלה 6. בסעיף ד(2), מי שמחשב את האינטגרל ישר מ-−9 עד 0 בלי לפצל ב-x = −3 מקבל 18 − 1128 = 15128, כי החלק השלילי מקוזז. ועוד: מי שלא מזהה ש-h = g · g′ היא נגזרת של ½g² נכנס לאינטגרל של שבר ממעלה חמישית. הצורה "פונקצייה כפול הנגזרת שלה" היא רמז מובהק.

שאלה 7, פונקצייה טריגונומטרית עם פרמטר (20 נקודות)

הנתונים. f(x) = (1 + cos x)(−1 + b cos x), בתחום −π ≤ x ≤ π, ו-0 < b < 1.

סעיף א: זוגית או אי-זוגית

הפונקצייה cos x זוגית: cos(−x) = cos x. לכן

f(−x) = (1 + cos(−x))(−1 + b cos(−x)) = (1 + cos x)(−1 + b cos x) = f(x)

גם התחום −π ≤ x ≤ π סימטרי סביב 0. f זוגית.

(היא אינה אי-זוגית: f(0) = 2(b − 1) ≠ 0, ואילו פונקצייה אי-זוגית המוגדרת ב-0 חייבת להתאפס שם.)

סעיף ב: נקודות החיתוך עם ציר ה-x

מכפלה מתאפסת כשאחד הגורמים מתאפס.

  • 1 + cos x = 0, כלומר cos x = −1. בתחום הנתון: x = −π או x = π.
  • −1 + b cos x = 0, כלומר cos x = 1b. אבל 0 < b < 1, ולכן 1b > 1, ו-cos x לעולם אינו גדול מ-1. אין פתרון.

נקודות החיתוך: (−π , 0) ו-(π , 0).

סעיף ג: הערך של b

נגזור לפי כלל המכפלה:

f′(x)= (−sin x)(−1 + b cos x) + (1 + cos x)(−b sin x)= sin x · [1 − b cos x − b − b cos x]= sin x · (1 − b − 2b cos x)

בנקודת קיצון פנימית הנגזרת מתאפסת. ב-x = π3: sin(π3) = √32 ≠ 0, ו-cos(π3) = ½, ולכן הגורם השני חייב להתאפס:

1 − b − 2b · ½ = 0
1 − 2b = 0
b = 12

נוודא שזו באמת נקודת קיצון: עם b = ½, f′(x) = sin x · (½ − cos x). סביב π3 sin x חיובי, ו-½ − cos x עובר משלילי (משמאל, שם cos x > ½) לחיובי (מימין). הנגזרת מחליפה סימן, ולכן זה קיצון. b = 12.

סעיף ד: קיצון וסקיצה (b = ½)

f(x) = (1 + cos x)(−1 + ½ cos x), f′(x) = sin x · (½ − cos x)

(1) נקודות הקיצון. f′(x) = 0 כאשר:

  • sin x = 0: בתחום, x = −π, 0, π.
  • cos x = ½: בתחום, x = −π3, π3.

נחשב את הערכים:

טבלת סימנים של f′. נעבור על החצי הימני, והשמאלי זהה בשיקוף כי f זוגית:

0 < x < π3: sin x > 0, cos x > ½ ⇒ ½ − cos x < 0 ⇒ f′ < 0, יורדת
π3 < x < π: sin x > 0, cos x < ½ ⇒ ½ − cos x > 0 ⇒ f′ > 0, עולה
−π3 < x < 0: sin x < 0, cos x > ½ ⇒ f′ > 0, עולה
−π < x < −π3: sin x < 0, cos x < ½ ⇒ f′ < 0, יורדת

נקודות הקיצון:

  • מינימום: (−π3 , −98) ו-(π3 , −98).
  • מקסימום: (0 , −1).
  • נקודות הקצה (−π , 0) ו-(π , 0) הן נקודות מקסימום: מ-(−π , 0) הפונקצייה יורדת, ואל (π , 0) היא עולה.

(2) סקיצה. הגרף מתחיל ב-(−π , 0), יורד עד המינימום (−π3 , −98), עולה עד המקסימום (0 , −1), יורד שוב עד המינימום (π3 , −98) ועולה עד (π , 0). צורה של האות W, סימטרית סביב ציר ה-y, וכולה מתחת לציר ה-x פרט לשתי נקודות הקצה, שבהן היא נוגעת בו.

סעיף ה: הנקודה A על הגרף של h(x) = f(x) + |f(x)|

נזכור את הכלל של ערך מוחלט: אם מספר אי-שלילי, |f| = f; אם הוא שלילי, |f| = −f. לכן

f(x)≥ 0 ⇒ h(x) = f(x) + f(x) = 2f(x)f(x)< 0 ⇒ h(x) = f(x) − f(x) = 0

השאלה היא אם כן איפה f חיובית. מסעיף ד, הערך הגבוה ביותר של f בתחום הוא 0 (בנקודות הקצה). אפשר לראות את זה גם ישירות מן הגורמים: 1 + cos x ≥ 0 תמיד, ו-−1 + ½ cos x ≤ −1 + ½ = −½ < 0 תמיד, ולכן המכפלה אינה חיובית אף פעם:

f(x) ≤ 0 לכל −π ≤ x ≤ π

לכן |f(x)| = −f(x) בכל התחום (גם במקומות שבהם f = 0), ו-

h(x) = f(x) − f(x) = 0 לכל x בתחום

הגרף של h הוא הקטע של ציר ה-x מ-−π עד π, וכל נקודה עליו היא בגובה 0.

שיעור ה-y של הנקודה A שווה אפס.

שאלה 8, פונקציית שורש וישר (20 נקודות)

הנתונים. f(x) = 2√x² − 1, והישר y = 3x − 3.

סעיף א: תחום ההגדרה

הביטוי שבתוך השורש חייב להיות אי-שלילי:

x² − 1 ≥ 0
x² ≥ 1

סעיף ב: נקודות החיתוך עם הישר

2√x² − 1 = 3x − 3

לפני שמעלים בריבוע: אגף שמאל שורש, ולכן אי-שלילי. לכן גם אגף ימין חייב להיות אי-שלילי: 3x − 3 ≥ 0, כלומר x ≥ 1. נעלה בריבוע:

4(x² − 1) = 9(x − 1)²
4(x − 1)(x + 1) = 9(x − 1)²

לא מחלקים ב-(x − 1), כי כך הולך לאיבוד פתרון. מעבירים אגף ומוציאים גורם משותף:

(x − 1)[4(x + 1) − 9(x − 1)] = 0
(x − 1)(−5x + 13) = 0
x = 1 או x = 135 = 2.6

שני הפתרונות מקיימים x ≥ 1. נחשב את שיעורי ה-y בעזרת הישר:

סעיף ג: אורכי הקטעים AB ו-AC

הנקודה A על הגרף, ושיעור ה-x שלה t, ולכן

A(t , 2√t² − 1), 1 < t < 2.6

מי למעלה? בין שתי נקודות החיתוך, הגרף של f מעל הישר. נבדוק בנקודה אחת, למשל t = 2: f(2) = 2√3 ≈ 3.46, ואילו הישר נותן 3. גם הסרטוט מראה זאת.

(1) AB. הישר דרך A המקביל לציר ה-y הוא x = t. הוא פוגש את הישר הנתון בנקודה B(t , 3t − 3). לשתי הנקודות אותו שיעור x, ולכן האורך הוא הפרש שיעורי ה-y, הגבוה פחות הנמוך:

AB = 2√t² − 1 − (3t − 3) = 2√t² − 1 − 3t + 3.

(2) AC. הישר דרך A המקביל לציר ה-x הוא y = 2√t² − 1. נמצא איפה הוא פוגש את הישר הנתון:

זה שיעור ה-x של C. הנקודה A מעל הישר, והישר עולה, ולכן כדי להגיע לאותו גובה צריך ללכת ימינה: C מימין ל-A. האורך הוא הפרש שיעורי ה-x:

הדף הזה אינו מסמך רשמי של משרד החינוך, ואינו מאושר על ידו.
