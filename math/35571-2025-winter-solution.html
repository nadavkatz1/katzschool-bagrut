לפני שמתחילים

זה השאלון הראשון של 5 יחידות לימוד בתוכנית החדשה. יש בו שמונה שאלות בארבעה פרקים: שאלות קצרות (שאלה 1), אינדוקצייה, סדרות והסתברות (שאלות 2 ו-3), גאומטרייה וטריגונומטרייה במישור (שאלות 4 ו-5), וחשבון דיפרנציאלי ואינטגרלי (שאלות 6 עד 8).

עונים על חמש שאלות: לפחות על שאלה אחת מן הפרק הראשון או השני, ולפחות על שאלה אחת מכל אחד מן הפרקים השלישי והרביעי. כל שאלה שווה 20 נקודות, וחמש שאלות הן 100 נקודות. מי שעונה על יותר מחמש שאלות, נבדקות לו רק חמש התשובות הראשונות שבמחברת. בשאלה 1 עונים על שניים מארבעת הסעיפים א עד ד, וגם שם נבדקות רק שתי התשובות הראשונות. השאלון אינו מפרט ניקוד לתת-סעיפים.

משך הבחינה ארבע שעות ורבע. מותרים מחשבון לא גרפי ודפי הנוסחאות המצורפים.

כאן פתורות כל שמונה השאלות, ובשאלה 1 כל ארבעת הסעיפים, כדי שכל בחירה אפשרית של תלמיד תהיה מכוסה. בכל שאלה מופיעים הנתונים, השלבים והנימוק לכל שלב, ובסופה הערה קצרה על המקום שבו נופלים.

שאלה 1, ארבעה סעיפים קצרים (20 נקודות)

עונים על שניים מן הסעיפים. כל סעיף כאן עומד בפני עצמו.

סעיף א: אינדוקצייה על n זוגי

הנתונים. השוויון

8 + 24 + 48 + ... + n(n + 2) = n(n + a)(n + 4) / 6

מתקיים עבור n = 2, ו-a הוא פרמטר.

לפני שמתחילים, נבין איך הסכום בנוי. האיבר הכללי הוא m(m + 2), ו-m רץ על המספרים הזוגיים 2, 4, 6 וכן הלאה עד n:

m= 2: 2 · 4 = 8m= 4: 4 · 6 = 24m= 6: 6 · 8 = 48

(1) הערך של a. עבור n = 2 יש באגף שמאל איבר אחד בלבד, 8. נציב n = 2 באגף ימין ונשווה:

2 · (2 + a) · 6 / 6 = 8
2(2 + a) = 8
2 + a = 4
a = 2

a = 2.

(2) ההוכחה. עם a = 2 צריך להוכיח שלכל n טבעי זוגי

8 + 24 + 48 + ... + n(n + 2) = n(n + 2)(n + 4) / 6

הטענה נוגעת רק ל-n זוגי, ולכן צעד האינדוקצייה עובר מ-n ל-n + 2, ולא ל-n + 1.

בדיקה עבור n = 2. אגף שמאל 8, אגף ימין 2 · 4 · 6 / 6 = 8. הטענה נכונה.

הנחת האינדוקצייה. נניח שעבור n זוגי מסוים מתקיים

8 + 24 + ... + n(n + 2) = n(n + 2)(n + 4) / 6

צריך להוכיח את הטענה עבור n + 2, כלומר

8 + 24 + ... + n(n + 2) + (n + 2)(n + 4) = (n + 2)(n + 4)(n + 6) / 6

האיבר החדש הוא האיבר הכללי m(m + 2) עם m = n + 2, כלומר (n + 2)(n + 4).

ההוכחה. נחליף את כל האיברים עד n(n + 2) לפי ההנחה, ונוציא גורם משותף:

n(n + 2)(n + 4) / 6 + (n + 2)(n + 4)
= (n + 2)(n + 4) · [n6 + 1]= (n + 2)(n + 4) · (n + 6) / 6

קיבלנו בדיוק את אגף ימין עבור n + 2. לפי עקרון האינדוקצייה, השוויון מתקיים לכל n טבעי זוגי.

סעיף ב: מועמדים ושני מבחנים

הנתונים. נסמן:

p = ההסתברות שמועמד הצליח רק במבחן הראשון
x = ההסתברות שמועמד הצליח בשני המבחנים
y = ההסתברות שמועמד הצליח רק במבחן השני

מספר המועמדים שהצליחו רק בראשון קטן פי 4 ממספר המועמדים שהצליחו בשניהם, ולכן

x = 4p

מן המועמדים שהצליחו במבחן השני, 89 הצליחו גם בראשון. מי שהצליח בשני הוא מי שהצליח בשניהם או רק בשני, ולכן

x / (x + y) = 89

(1) נציב x = 4p:

4p / (4p + y) = 89
36p = 32p + 8y
4p = 8y
y = 0.5p

מי שהצליח לפחות במבחן אחד הצליח רק בראשון, רק בשני או בשניהם:

p + 4p + 0.5p = 5.5p

ההסתברות שמועמד הצליח לפחות במבחן אחד היא 5.5p, כלומר 11p2.

(2) זו הסתברות מותנית. ידוע שהמועמד הצליח לפחות במבחן אחד, ושואלים מה ההסתברות שהצליח בשניהם:

P(בשניהם | לפחות באחד) = 4p / 5.5p = 811

ההסתברות היא 811, בקירוב 0.727. שימו לב ש-p מצטמצם, ולכן אין צורך לדעת אותו.

סעיף ג: שלוש פונקציות דומות

הנתונים.

f(x)= x / √x² − 1g(x)= √x / (x² − 1)h(x)= √ x / (x² − 1)

שלוש הפונקציות בנויות מאותם חלקים, וההבדל ביניהן הוא מה נמצא מתחת לשורש. זה בדיוק מה שקובע את תחום ההגדרה.

(1) תחומי ההגדרה.

f: השורש במכנה, ולכן הביטוי שמתחתיו חייב להיות חיובי ממש (אפס אסור במכנה):

x² − 1 > 0 ⟺ x < −1 או x > 1

g: השורש במונה, ולכן x ≥ 0. בנוסף המכנה לא יתאפס, x² ≠ 1. מבין 1 ו-−1 רק x = 1 נמצא בתחום x ≥ 0:

x ≥ 0 , x ≠ 1

h: כל השבר מתחת לשורש, ולכן השבר צריך להיות אי-שלילי, והמכנה לא יתאפס. נבנה טבלת סימנים לשבר x / ((x − 1)(x + 1)), עם נקודות החלוקה −1, 0, 1:

תחוםxx² − 1השבר
x < −1שליליחיובישלילי
−1 < x < 0שלילישליליחיובי
0 < x < 1חיובישלילישלילי
x > 1חיוביחיוביחיובי

ב-x = 0 השבר שווה 0, וזה מותר מתחת לשורש. מכאן

−1 < x ≤ 0 או x > 1

(2) התאמת הגרפים. נתאים לפי התחומים, ובמקום שהתחום לבדו לא מכריע, לפי הסימן.

f מתאימה לגרף 3. f היא היחידה שאינה מוגדרת בכלל בין −1 ל-1, וגרף 3 הוא היחיד שאין בו שום חלק בין שני הקווים המקווקווים האנכיים. זה מתאים גם לאסימפטוטות האופקיות שבגרף 3: כש-x גדל מאוד, √x² − 1 קרוב ל-|x|, ולכן f מתקרבת ל-1 מימין ול-−1 משמאל.

g מתאימה לגרף 1. g היחידה שאינה מוגדרת לשום x שלילי, וגרף 1 הוא היחיד שאין לו שום חלק משמאל לציר ה-y. בדיקה: g(0) = 0, ובתחום 0 < x < 1 המונה חיובי והמכנה שלילי, ולכן הגרף יורד מן הראשית אל מתחת לציר ה-x, כמו בגרף 1.

h מתאימה לגרף 5. לפי התחום, h צריכה להיות מוגדרת בין −1 ל-0 (כולל 0) ומימין ל-1. שני גרפים בנויים כך, 4 ו-5. אבל h היא שורש, ולכן היא אינה שלילית לעולם. בגרף 4 הענף שמימין ל-1 נמצא מתחת לציר ה-x, ולכן h מתאימה לגרף 5.

גרפים 2 ו-4 אינם מתאימים לאף אחת מן הפונקציות.

סעיף ד: גרף הנגזרת והשטח

הנתונים. f(x) ו-f′(x) מוגדרות לכל x. f אי-זוגית, ויש לה נקודת מינימום אחת בלבד, (3 , −6). ל-f ול-f′ יש אסימפטוטה אופקית y = 0.

מן האי-זוגיות נובעים שני דברים חשובים: f(0) = 0, ולמינימום (3 , −6) יש "תמונת מראה" שהיא מקסימום, (−3 , 6). זה גם מה שרואים בסרטוט.

(1) סקיצה של f′(x). נקרא את הסרטוט של f משמאל לימין ונתרגם כל קטע לסימן של הנגזרת:

תחוםמה עושה fהסימן של f′
x < −3עולהחיובי
x = −3מקסימוםf′ = 0
−3 < x < 3יורדתשלילי
x = 3מינימוםf′ = 0
x > 3עולהחיובי

ועוד שלושה פרטים שעוזרים לצייר נכון:

  • הנגזרת של פונקצייה אי-זוגית היא פונקצייה זוגית, ולכן הגרף של f′ סימטרי לציר ה-y.
  • הירידה של f הכי תלולה בראשית, ולכן ל-f′ יש מינימום (שלילי) ב-x = 0.
  • ל-f′ אסימפטוטה y = 0. מימין ל-3 הנגזרת חיובית ובסוף חוזרת אל 0, ולכן היא עולה ואחר כך יורדת: יש לה מקסימום בנקודה כלשהי מימין ל-3, ובאופן סימטרי גם משמאל ל-−3.

הסקיצה: הגרף מתחיל קרוב לציר ה-x מלמעלה בצד שמאל, עולה למקסימום, יורד וחותך את ציר ה-x ב-x = −3, ממשיך לרדת עד מינימום ב-x = 0 (מתחת לציר), עולה וחותך את ציר ה-x ב-x = 3, עולה למקסימום ויורד בחזרה אל ציר ה-x מלמעלה. כל הגרף סימטרי לציר ה-y.

(2) נקודות החיתוך של g(x) = f²(x) · f′(x) עם ציר ה-x. מכפלה מתאפסת כשאחד הגורמים מתאפס.

  • f′(x) = 0: לפי סעיף (1), ב-x = −3 וב-x = 3.
  • f(x) = 0: f אי-זוגית ולכן f(0) = 0. זו נקודת האפס היחידה של f: מימין לראשית f יורדת עד −6, ואחר כך עולה לעבר 0 בלי להגיע אליו (y = 0 אסימפטוטה), ולכן היא שלילית לכל x > 0. מן האי-זוגיות היא חיובית לכל x < 0.

נקודות החיתוך עם ציר ה-x: (−3 , 0) , (0 , 0) , (3 , 0).

(3) השטח. הסימן של g הוא הסימן של f′, כי f² אינו שלילי. בתחום −3 < x < 3 הנגזרת שלילית, ולכן g ≤ 0 שם: הגרף נמצא מתחת לציר ה-x, ונוגע בו ב-x = 0. מימין ל-3 ומשמאל ל-−3 התחום אינו חסום, ולכן השטח המוגבל הוא השטח שבין −3 ל-3.

כאן המפתח של השאלה. לא ידועה לנו הנוסחה של f, ולכן צריך פונקצייה קדומה שאפשר לחשב בלי נוסחה. לפי כלל השרשרת

( f³(x) / 3 )′ = 3f²(x) · f′(x) / 3 = f²(x) · f′(x) = g(x)

ולכן f³(x)3 היא פונקצייה קדומה של g, ומספיק לדעת את ערכי f בקצוות: f(−3) = 6, f(0) = 0, f(3) = −6.

∫ מ-−3 עד 0 של g = f³(0)3 − f³(−3)3 = 0 − 2163 = −72
∫ מ-0 עד 3 של g = f³(3)3 − f³(0)3 = −2163 − 0 = −72

שני האינטגרלים שליליים, כי השטח מתחת לציר ה-x. השטח הוא הערך המוחלט:

S = 72 + 72 = 144

השטח הוא 144 יחידות שטח.

איפה נופלים בשאלה 1. בסעיף א מקדמים את האינדוקצייה מ-n ל-n + 1, ואז האיבר החדש הוא (n + 1)(n + 3), שאינו בכלל בסכום. בסעיף ג(1) מוציאים את x = 0 מן התחום של g או של h, אף שבשתיהן x = 0 נותן שורש של 0, וזה מותר. בסעיף ג(2) מתאימים את h לגרף 4 לפי התחום בלבד, ושוכחים ששורש אינו שלילי. בסעיף ד(3) מחפשים נוסחה של f, ואין צורך: g היא בדיוק הנגזרת של f³3.

פרק שני: אינדוקצייה, סדרות והסתברות

שאלה 2, סדרות הנדסיות (20 נקודות)

הנתונים. A היא סדרה הנדסית a₁ , a₂ , a₃ , ... ובה m איברים, m טבעי גדול מ-4. כל איברי A שליליים. סכום m − 4 האיברים האחרונים גדול פי 16 מסכום m − 4 האיברים הראשונים.

סעיף א: המנה והמונוטוניות

(1) נסמן את המנה ב-q. נסתכל על שתי הקבוצות של m − 4 איברים:

הראשונים: a₁ , a₂ , ... , a(m−4)
האחרונים: a₅ , a₆ , ... , a(m)

כל איבר בקבוצה השנייה רחוק ארבעה מקומות מן האיבר המתאים בקבוצה הראשונה: a₅ = a₁q⁴, a₆ = a₂q⁴, וכן הלאה. לכן הסכום של האחרונים הוא q⁴ כפול הסכום של הראשונים:

q⁴ · (a₁ + ... + a(m−4)) = 16 · (a₁ + ... + a(m−4))

הסכום של הראשונים אינו 0 (כל האיברים שליליים), ולכן מותר לחלק בו:

q⁴ = 16
q = 2 או q = −2

אם q = −2, האיברים מחליפים סימן לסירוגין, ואז לא כולם שליליים. לכן

q = 2.

(2) נבדוק את ההפרש בין שני איברים סמוכים:

a(n+1) − a(n) = a(n) · q − a(n) = a(n) · (q − 1) = a(n) · 1 = a(n)

כל איבר שלילי, ולכן ההפרש שלילי, וכל איבר קטן מקודמו.

הסדרה A יורדת. (למשל, אם a₁ = −1 הסדרה היא −1 , −2 , −4 , ... ובאמת יורדת.)

סעיף ב: הסדרה B הנדסית

ממשיכים את A לסדרה הנדסית אין-סופית, ומגדירים b(n) = kⁿ / a(n), k ≠ 0. סדרה היא הנדסית אם המנה בין כל איבר לקודמו קבועה. נחשב:

b(n+1) / b(n)= [kn+1 / a(n+1)] · [a(n) / kⁿ]= k · a(n) / a(n+1)= k · 1q= k2

(החלוקה מותרת: k ≠ 0 ו-a(n) ≠ 0, ולכן אף איבר של B אינו 0.)

המנה k2 אינה תלויה ב-n, ולכן B סדרה הנדסית, ומנתה k2.

סעיף ג: תחום הערכים של k

סכום של סדרה הנדסית אין-סופית מתכנס כשהערך המוחלט של המנה קטן מ-1:

|k2| < 1
−2 < k < 2

ונזכור ש-k ≠ 0 לפי הנתון. התחום: −2 < k < 2 , k ≠ 0.

סעיף ד: k ו-b₁

המנה של B היא 14, ולפי סעיף ב היא k2:

k2 = 14
k = 12

הסכום של B הוא −9. לפי נוסחת הסכום של סדרה הנדסית אין-סופית:

b₁ / (1 − 14) = −9
b₁ = −9 · 34 = −274

k = 12 , b₁ = −274 = −6.75.

סעיף ה: מוחקים כל איבר שלישי

מוחקים את b₃ , b₆ , b₉ , ... ושואלים מה סכום מה שנשאר. הדרך הנוחה: לחשב את סכום האיברים שנמחקו ולהחסיר אותו מן הסכום הכולל.

האיברים שנמחקו הם עצמם סדרה הנדסית. האיבר הראשון שלה הוא b₃, והמעבר מ-b₃ ל-b₆ הוא שלושה צעדים, ולכן המנה שלה היא (14)³:

המנה = (14)³ = 164
סכום הנמחקים = (−2764) / (1 − 164) = (−2764) · (6463) = −2763 = −37

ולכן

סכום הנותרים = −9 − (−37) = −637 + 37 = −607

שאלה 3, הסתברות עם שני כדים (20 נקודות)

סעיף א: שני כדורים באותו צבע

התהליך של דנה. היא בוחרת כד ומוציאה כדור. אם הוא צהוב, היא מוציאה כדור שני מאותו כד בלי להחזיר. אם הוא אדום, היא מחזירה אותו ומוציאה שוב מאותו כד. בכל מקרה היא מוציאה שני כדורים.

נעבור על כל המקרים שבהם שני הכדורים באותו צבע:

כד ב'. בכד יש רק אדומים, ולכן שני הכדורים אדומים בוודאות:

כד א', שני צהובים. הראשון צהוב (1525). הוא לא מוחזר, ולכן נשארו 14 צהובים מתוך 24:

ההסתברות היא 35151, בקירוב 0.232.

פרק שלישי: גאומטרייה וטריגונומטרייה במישור

שאלה 4, משיק, מיתר ודמיון (20 נקודות)

הנתונים. במרובע BKCD הצלע KB מקבילה לצלע CD. CD מיתר במעגל, ו-KB משיקה למעגל בנקודה K. הצלע BD חותכת את המעגל בנקודה A. האלכסון BC חותך את המיתר AK בנקודה E.

לפי הסרטוט, הנקודות K, A, D, C נמצאות על המעגל בסדר הזה, ו-A נמצאת בין B ל-D.

סעיף א: △ABK ∼ △AKC

נמצא שני זוגות של זוויות שוות.

זוג ראשון. KB משיק ו-KA מיתר. הזווית בין משיק למיתר שווה לזווית ההיקפית הנשענת על אותו מיתר מן הצד השני, ו-C נמצאת על הקשת שמן הצד השני:

∢BKA = ∢KCA

זוג שני. KB ∥ CD, ו-BD חותך את שניהם. הזוויות ∢KBD ו-∢BDC הן זוויות חד-צדדיות בין ישרים מקבילים, ולכן

∢KBA + ∢ADC = 180°

(∢KBA היא ∢KBD, ו-∢ADC היא ∢BDC, כי A נמצאת על הקטע BD.)

מצד שני, KADC מרובע חסום במעגל, וסכום שתי זוויות נגדיות בו 180°:

∢AKC + ∢ADC = 180°

משתי המשוואות: ∢KBA = ∢AKC.

לכן △ABK ∼ △AKC לפי ז.ז., בהתאמה

A ↔ A , B ↔ K , K ↔ C

ומכאן גם הזווית השלישית: ∢BAK = ∢KAC. נשתמש בזה מייד.

סעיף ב: ABAC = BECE

לפי סעיף א, ∢BAK = ∢KAC. כלומר הקטע AK חוצה את הזווית BAC.

הנקודה E נמצאת גם על AK וגם על BC. לכן במשולש ABC, הקטע AE הוא חוצה הזווית A, והוא פוגש את הצלע שמולה, BC, בנקודה E. לפי משפט חוצה הזווית במשולש:

AB / AC = BE / CE

וזה מה שהיה צריך להוכיח.

סעיף ג: היחס AKAB

נתון BE = CE4, כלומר BECE = 14, ולפי סעיף ב

AB / AC = 14 ⟺ AC = 4 · AB

מן הדמיון בסעיף א, היחס בין הצלעות המתאימות:

AB / AK = AK / AC

כלומר

AK² = AB · AC = AB · 4AB = 4AB²
AK = 2AB

AKAB = 2.

סעיף ד: שטח המשולש KEC

האלכסונים של המרובע ABKC הם AK ו-BC, והם נחתכים ב-E. לכן הם מחלקים אותו לארבעה משולשים: AEB, BEK, KEC, CEA. נבטא כל אחד מהם.

משולשים עם קודקוד משותף ובסיסים על אותו ישר. שני משולשים שיש להם קודקוד משותף, ובסיסיהם על אותו ישר, נמצאים באותו גובה, ולכן היחס בין שטחיהם הוא היחס בין הבסיסים. כאן הבסיסים על BC, ו-CE = 4BE:

S(AEC) / S(AEB)= CE / BE = 4 ⟺ S(AEC) = 4SS(KEC) / S(KEB)= CE / BE = 4 ⟺ S(KEC) = 4 · S(KEB)

נסמן S(KEB) = T. אז S(KEC) = 4T.

השטח הכולל.

S + T + 4T + 4S = 18
5S + 5T = 18
T = 3.6 − S

ולכן

S(KEC) = 4T = 4(3.6 − S) = 14.4 − 4S

שטח המשולש KEC הוא 14.4 − 4S (כלומר 725 − 4S).

הנתונים אינם קובעים את S עצמו: גם במשולשים דומים עם ABAC = 14 הזווית BAC עדיין יכולה להשתנות, ולכן השאלה מבקשת תשובה באמצעות S.

איפה נופלים בשאלה 4. בסעיף א בוחרים את הזווית ההיקפית הלא נכונה עבור המשיק: הזווית בין המשיק KB למיתר KA שווה לזווית ההיקפית מן הקשת השנייה, כלומר בקודקוד C. בסעיף ב מחפשים דמיון נוסף, וכל מה שצריך הוא לשים לב ש-AE חוצה זווית. בסעיף ד מנסים לחשב את S, ואין לו ערך יחיד.

שאלה 5, שני משיקים ומשולש (20 נקודות)

הנתונים. מעגל שמרכזו O ורדיוסו R. מן הנקודה A יוצאים שני ישרים, AB ו-AC, המשיקים למעגל. E היא נקודת ההשקה של AC. נתון BO ⊥ AO ו-AE = CE, ומסמנים ∢BAC = 2β.

עובדה שנשתמש בה כל הזמן: מרכז מעגל המשיק לשתי שוקי זווית נמצא על חוצה הזווית. לכן AO חוצה את ∢BAC, ו-∢OAB = ∢OAC = β.

סעיף א: AB באמצעות R ו-β

נסמן ב-F את נקודת ההשקה של AB. הרדיוס לנקודת השקה מאונך למשיק, ולכן OF ⊥ AB ו-OF = R.

במשולש AFO (ישר זווית ב-F), הזווית ב-A היא β:

sin β = OF / AO = R / AO ⟺ AO = R / sin β

במשולש AOB (ישר זווית ב-O, כי BO ⊥ AO), הזווית ב-A היא β, ו-AB הוא היתר:

cos β = AO / AB ⟺ AB = AO / cos β = R / (sin β · cos β)

ולפי sin 2β = 2 sin β cos β:

AB = R / (sin β · cos β) = 2R / sin 2β.

סעיף ב: הערך של β

נתון AB = 2.5R:

2R / sin 2β = 2.5R
sin 2β = 22.5 = 0.8

הזווית BAC = 2β חדה, ולכן

2β ≈ 53.13°
β ≈ 26.57°

β ≈ 26.57°. (ערך מדויק: cos 2β = 0.6, ולכן tan β = sin 2β / (1 + cos 2β) = 0.81.6 = 12. זה יעזור מאוד בסעיפים הבאים.)

סעיף ג: היחס בין השטחים

שטח AOB. AB משיק למעגל, ולכן המרחק מ-O אל AB הוא R. זה הגובה מ-O לצלע AB:

S(AOB) = 12 · AB · R = 12 · 2.5R · R = 1.25R²

שטח ABC. קודם צריך את AC. AE הוא קטע משיק, ובמשולש AEO (ישר זווית ב-E):

tan β = OE / AE = R / AE ⟺ AE = R / tan β = R / (12) = 2R

נתון AE = CE, ולכן AC = 2AE = 4R. השטח לפי שתי צלעות והזווית שביניהן:

S(ABC) = 12 · AB · AC · sin 2β = 12 · 2.5R · 4R · 0.8 = 4R²

היחס:

S(ABC) / S(AOB) = 4R² / 1.25R² = 3.2

היחס הוא 16 : 5, כלומר 3.2.

סעיף ד: הערך של R

שימו לב למילה שמתחתיה קו בשאלון: המעגל החוסם את המשולש ABC. זה המעגל שעובר דרך שלושת הקודקודים A, B ו-C, והוא מעגל אחר, לא המעגל שבסרטוט. נסמן את הרדיוס שלו ב-r, ונתון r = 8.

את הרדיוס של המעגל החוסם נותן משפט הסינוסים: צלע חלקי הסינוס של הזווית שמולה שווה ל-2r. את הזווית שמול BC אנחנו מכירים, ∢BAC = 2β ו-sin 2β = 0.8. חסרה לנו הצלע BC, ונמצא אותה במשפט הקוסינוסים (cos 2β = 0.6):

BC²= AB² + AC² − 2 · AB · AC · cos 2β= 6.25R² + 16R² − 2 · 2.5R · 4R · 0.6= 6.25R² + 16R² − 12R²= 10.25R²
BC = R · √10.25 = R · √41 / 2

ועכשיו משפט הסינוסים במשולש ABC, עם r = 8:

BC / sin 2β = 2r
(R · √41 / 2) / 0.8 = 16
R · √41 / 1.6 = 16
R = 25.6 / √41 ≈ 3.998

R = 25.6√41 ≈ 4.

בדיקה קצרה: עם R = 4 הצלעות הן AB = 10, AC = 16, BC ≈ 12.81, ו-BC / sin 2β ≈ 12.81 / 0.8 ≈ 16, כלומר רדיוס המעגל החוסם הוא בערך 8, כמו בנתון.

איפה נופלים בשאלה 5. בסעיף א שוכחים ש-AO חוצה את הזווית, ולוקחים את הזווית ב-A כ-2β במקום β. בסעיף ב שוכחים את הנתון "זווית חדה", ואז יש שני פתרונות, 2β = 53.13° או 2β = 126.87°. בסעיף ד מבלבלים בין המעגל החוסם (עובר דרך הקודקודים, ומוצאים את הרדיוס שלו במשפט הסינוסים) לבין המעגל החסום (משיק לצלעות מבפנים, והרדיוס שלו הוא השטח חלקי חצי ההיקף). מי שמחשב כאן מעגל חסום מקבל R ≈ 9.70, וזו תשובה לשאלה אחרת. ועוד בלבול: המעגל שבסרטוט אינו אף אחד מהשניים. הוא משיק ל-AB ול-AC, אבל הצלע BC חותכת אותו.

פרק רביעי: חשבון דיפרנציאלי ואינטגרלי

שאלה 6, מן הנגזרת אל הפונקצייה (20 נקודות)

הנתונים. הנגזרת של f היא

f′(x) = −4x / (x² − a²)³ , a > 0

ו-f ו-f′ מוגדרות באותו תחום.

סעיף א: תחום ההגדרה של f′

המכנה מתאפס כש-x² = a², כלומר x = a או x = −a.

התחום: x ≠ a , x ≠ −a.

סעיף ב: תחומי עלייה וירידה של f

הסימן של f′ נקבע לפי המונה, −4x, ולפי המכנה (x² − a²)³. חזקה שלישית שומרת על הסימן, ולכן הסימן של המכנה הוא הסימן של x² − a²: חיובי מחוץ לקטע בין −a ל-a, ושלילי בתוכו.

תחום−4x(x² − a²)³f′f
x < −aחיוביחיוביחיוביעולה
−a < x < 0חיובישלילישלילייורדת
0 < x < aשלילישליליחיוביעולה
x > aשליליחיובישלילייורדת

f עולה בתחום x < −a ובתחום 0 < x < a. f יורדת בתחום −a < x < 0 ובתחום x > a.

סעיף ג: מציאת f

צריך פונקצייה קדומה של f′. נשים לב שהמונה, עד כדי קבוע, הוא הנגזרת של מה שבתוך הסוגריים: (x² − a²)′ = 2x. לכן ננחש את הצורה 1(x² − a²)² ונגזור לבדיקה:

[ (x² − a²)−2 ]′ = −2 · (x² − a²)−3 · 2x = −4x / (x² − a²)³

בדיוק f′. לכן

f(x) = 1(x² − a²)² + C

כש-x שואף לאין-סוף, השבר שואף ל-0, ולכן f שואפת ל-C. האסימפטוטה האופקית היא y = 0, ולכן C = 0. השאלה מבקשת פונקצייה אחת המקיימת את התנאים, ולכן ניקח את אותו ביטוי בכל התחום.

f(x) = 1(x² − a²)².

סעיף ד: התאמת הגרפים

נתונות גם

g(x) = (x − a) / (x² − a²)² , h(x) = (x − a)² / (x² − a²)²

והתחום של שלושתן הוא x ≠ ±a. הצעד החשוב: לפרק x² − a² = (x − a)(x + a) ולצמצם, ולזכור שהצמצום אינו מחזיר את x = a לתחום.

g(x)= (x − a) / [(x − a)² (x + a)²] = 1 / [(x − a)(x + a)²] (x ≠ ±a)h(x)= (x − a)² / [(x − a)² (x + a)²] = 1 / (x + a)² (x ≠ ±a)

f מתאימה לגרף II. f היא ריבוע במכנה, ולכן חיובית בכל התחום. היא זוגית, ויש לה שתי אסימפטוטות אנכיות, x = a ו-x = −a. ב-x = 0 יש לה מינימום (לפי סעיף ב), f(0) = 1a⁴ > 0. כך בדיוק נראה גרף II.

g מתאימה לגרף I. (x + a)² חיובי, ולכן הסימן של g הוא הסימן של x − a: שלילית לכל x < a (כולל משני צדי x = −a) וחיובית לכל x > a. ליד x = −a הגרף יורד ל-−∞ משני הצדדים, וליד x = a הוא יורד ל-−∞ משמאל ועולה ל-∞ מימין. כך בדיוק נראה גרף I.

h מתאימה לגרף III. h = 1(x + a)² חיובית, ויש לה אסימפטוטה אנכית אחת בלבד, x = −a, בצד השלילי. ב-x = a אין אסימפטוטה: הגורם (x − a)² הצטמצם, ונשאר "חור" בנקודה (a , 14a²). בגרף III האסימפטוטה בצד השלילי והחור בצד החיובי. בגרף IV המצב הפוך, ולכן הוא אינו מתאים.

סעיף ה: הערך של a

לפי סעיף ד, ל-h(x) = 1(x + a)² יש אסימפטוטה אנכית אחת, x = −a (ב-x = a יש רק חור). הפונקצייה h(x − 6) היא הזזה של h ב-6 יחידות ימינה, ולכן האסימפטוטה שלה היא במקום שבו x − 6 = −a:

x = 6 − a

נתון שהאסימפטוטה היא x = 0.25a:

6 − a = 0.25a
6= 1.25aa= 4.8

a = 4.8.

איפה נופלים בשאלה 6. בסעיף ב מניחים שהמכנה תמיד חיובי, כי "הוא בחזקה", אבל זו חזקה אי-זוגית. בסעיף ד שוכחים ש-x = a נשאר מחוץ לתחום של h גם אחרי הצמצום, ולכן מחליפים בין גרף III לגרף IV. בסעיף ה משווים גם את x = 6 + a ל-0.25a, אבל שם יש רק חור, לא אסימפטוטה (וממילא יוצא a שלילי).

שאלה 7, פונקצייה טריגונומטרית עם פרמטר (20 נקודות)

הנתונים.

f(x) = cos x + 2(cos x)² + a , −3π2 ≤ x ≤ 3π2

ו-a פרמטר.

סעיף א: תחום ההגדרה

המכנה (cos x)² לא יתאפס, כלומר cos x ≠ 0. בתחום הנתון cos x = 0 בארבע נקודות: x = −3π2, −π2, π2, 3π2. שתיים מהן הן קצות התחום.

התחום: −3π2 < x < 3π2 , x ≠ −π2 , x ≠ π2.

סעיף ב: זוגית או אי-זוגית

התחום סימטרי סביב 0, ו-cos(−x) = cos x. לכן

f(−x) = cos(−x) + 2(cos(−x))² + a = cos x + 2(cos x)² + a = f(x)

f זוגית.

סעיף ג: הערך של a

ישר אופקי משיק לגרף בנקודה שבה הנגזרת מתאפסת, כלומר בנקודת קיצון. נגזור. נכתוב 2(cos x)² = 2(cos x)−2:

f′(x)= −sin x + 2 · (−2)(cos x)−3 · (−sin x)= −sin x + 4 sin x / cos³x= sin x · (4/cos³x − 1)= sin x · (4 − cos³x) / cos³x

הגורם 4 − cos³x אינו מתאפס לעולם, כי cos³x ≤ 1. לכן f′ = 0 רק כש-sin x = 0, ובתחום זה x = 0, x = π, x = −π.

f(0)= 1 + 2 + a = 3 + af(π)= f(−π) = −1 + 2 + a = 1 + a

הישר y = 2 משיק לגרף בשתי נקודות. ב-x = 0 יש נקודה אחת בלבד, ולכן זה לא המקרה. ב-x = π וב-x = −π יש שתי נקודות עם אותו ערך:

1 + a = 2
a = 1

a = 1.

סעיף ד: נקודות הקיצון (a = 1)

f(x) = cos x + 2(cos x)² + 1

נקודות החשודות לקיצון: x = 0, π, −π (מסעיף ג). כדי לקבוע את הסוג נבדוק את הסימן של f′ = sin x · (4 − cos³x)/cos³x. המונה 4 − cos³x תמיד חיובי, ולכן הסימן של f′ נקבע לפי sin x ולפי cos x.

אין נקודות מקסימום: בכל קצה של כל קטע בתחום cos x שואף ל-0, ולכן 2(cos x)² שואף לאין-סוף. גם נקודות קצה אין, כי ±3π2 אינן בתחום.

סעיף ה: סקיצה

מה שצריך להופיע בסקיצה:

  • אסימפטוטות אנכיות: x = −3π2 , x = −π2 , x = π2 , x = 3π2.
  • שלושה ענפים בצורת U, ובכל אחד מהם הגרף עולה ל-∞ בשני הקצוות.
  • הענף האמצעי (בין −π2 ל-π2) עם מינימום ב-(0 , 4).
  • שני ענפים צדדיים, עם מינימום ב-(π , 2) וב-(−π , 2). הם נמוכים מן הענף האמצעי.
  • הגרף סימטרי לציר ה-y. הוא אינו יורד מתחת לישר y = 2, ונוגע בו רק בשתי נקודות המינימום הצדדיות. הוא אינו פוגש את ציר ה-x.

סעיף ו: g ו-h נפגשות בנקודות הקיצון

g(x) = f(x) − k , h(x) = 1/g(x) , k ≠ 4 , k ≠ 2

הקיצון של g. g היא f מוזזת אנכית, ולכן g′ = f′, והקיצון באותם ערכי x:

g(0) = 4 − k , g(π) = g(−π) = 2 − k

הקיצון של h. h′ = −g′g², ולכן h′ = 0 בדיוק כש-g′ = 0. הקיצון של h גם הוא ב-x = 0 וב-x = ±π. (התנאים k ≠ 4 ו-k ≠ 2 מבטיחים ש-g אינה מתאפסת שם, ולכן h מוגדרת בנקודות האלה.)

נפגשות. בכל אחת מנקודות הקיצון g = h, כלומר g = 1g:

g² = 1 ⟺ g = 1 או g = −1

ב-x = 0:

4 − k= 1 ⟺ k = 34 − k= −1 ⟺ k = 5

ב-x = ±π:

2 − k= 1 ⟺ k = 12 − k= −1 ⟺ k = 3

הערך היחיד שמתאים לשתי הדרישות יחד הוא k = 3. בדיקה: g(0) = 1 = h(0), g(π) = −1 = h(π).

k = 3.

איפה נופלים בשאלה 7. בסעיף א שוכחים להוציא את קצות התחום ±3π2, שבהם גם cos x = 0. בסעיף ג לוקחים a = −1 מן הנקודה x = 0, אבל שם יש נקודת השקה אחת בלבד. בסעיף ו מחפשים נקודות קיצון חדשות ל-h, ושוכחים ש-1g מקבלת קיצון בדיוק באותם x כמו g.

שאלה 8, פונקציית שורש ובעיית קיצון (20 נקודות)

הנתונים. f(x) = x · √21 − x.

סעיף א: תחום וסימן

(1) הביטוי שמתחת לשורש אינו שלילי:

21 − x ≥ 0 ⟺ x ≤ 21

התחום: x ≤ 21.

(2) √21 − x אינו שלילי, והוא מתאפס רק ב-x = 21. לכן בכל נקודה אחרת הסימן של f הוא הסימן של x:

  • f מתאפסת ב-x = 0 וב-x = 21.
  • f חיובית בתחום 0 < x < 21.
  • f שלילית בתחום x < 0.

סעיף ב: סקיצה

השאלה מספרת שיש נקודת קיצון פנימית אחת ואין נקודות פיתול. כדי לצייר נכון, נמצא את הקיצון:

f′(x)= √21 − x + x · (−1) / (2√21 − x)= [2(21 − x) − x] / (2√21 − x)= (42 − 3x) / (2√21 − x)

f′ = 0 כש-x = 14. משמאל ל-14 הנגזרת חיובית, ומימין לה שלילית, ולכן זה מקסימום:

f(14) = 14 · √7 ≈ 37.04

מה שצריך להופיע בסקיצה:

  • כש-x שואף ל-−∞, f שואפת ל-−∞.
  • הגרף עולה, עובר בראשית (0 , 0), וממשיך לעלות עד המקסימום (14 , 14√7) ≈ (14 , 37.04).
  • משם הוא יורד עד נקודת הקצה (21 , 0), שבה הגרף נעצר. ליד הקצה הירידה תלולה מאוד.
  • הגרף קעור כלפי מטה לכל אורכו (אין נקודות פיתול).

סעיף ג: המלבן שהיקפו מקסימלי

נבנה את המלבן. C היא נקודת החיתוך עם החלק החיובי של ציר ה-x, כלומר C(21 , 0). נסמן את A על הגרף ברביע הראשון:

A(x , x√21 − x) , 0 < x < 21

האנך מ-A לציר ה-x פוגש אותו ב-B(x , 0). האנך מ-A לישר x = 21 פוגש אותו ב-D(21 , x√21 − x). המלבן ABCD:

רוחב: BC = 21 − x
גובה: AB = x√21 − x = f(x)

פונקציית ההיקף.

P(x) = 2(21 − x) + 2x√21 − x = 2[21 − x + f(x)]

גוזרים ומשווים לאפס. את f′ כבר חישבנו בסעיף ב:

P′(x) = 2[−1 + f′(x)] = 2[−1 + 42 − 3x2√21 − x]
P′(x) = 0 ⟺ (42 − 3x) / (2√21 − x) = 1
⟺ 42 − 3x = 2√21 − x

נציב t = √21 − x, t ≥ 0, ואז x = 21 − t²:

42 − 3(21 − t²) = 2t
42 − 63 + 3t²= 2t3t² − 2t − 21= 0
t = (2 ± √4 + 252) / 6 = (2 ± 16) / 6
t = 3 או t = −73 (נפסל, כי t ≥ 0)

t = 3 נותן 21 − x = 9, כלומר x = 12. נקודת הבדיקה: f′(12) = 42 − 362 · 3 = 1, כנדרש.
